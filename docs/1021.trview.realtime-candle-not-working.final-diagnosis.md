#### 1.2 실시간 데이터 병합 로직

```typescript
// Line 210-232: REST 데이터 + 실시간 데이터 자동 병합
const mergedChartData = useMemo<ChartCandle[]>(() => {
  if (!isMinuteTimeframe) {
    return chartData;  // 일봉은 실시간 미사용
  }

  const candleMap = new Map<string, ChartCandle>();

  // 1. REST API 데이터
  chartData.forEach((candle) => {
    candleMap.set(candle.timestamp, candle);
  });

  // 2. 완성된 분봉 (finalize 이벤트)
  finalizedCandles.forEach((candle) => {
    candleMap.set(candle.timestamp, candle);
  });

  // 3. 현재 진행 중인 분봉 (update 이벤트)
  if (currentCandle) {
    candleMap.set(currentCandle.timestamp, currentCandle);
  }

  return Array.from(candleMap.values()).sort(
    (a, b) => new Date(a.timestamp).getTime() - new Date(b.timestamp).getTime()
  );
}, [isMinuteTimeframe, chartData, finalizedCandles, currentCandle]);
```

**병합 전략**:

- REST API로 로드한 기본 데이터
- + WebSocket으로 받은 완성된 분봉 (`finalize`)
- + WebSocket으로 받은 현재 분봉 (`update`)
- → timestamp 기준으로 정렬하여 반환

## 🎯 근본 원인 분석

### 확인된 사실

1. ✅ 실시간 분봉 코드는 **완벽하게 구현**되어 있음
2. ✅ WebSocket 연결은 **정상** (호가 업데이트 수신 중)
3. ✅ WebSocket 메시지 라우팅 코드 **존재**
4. ✅ `/trview` 페이지는 올바르게 Hook 호출

### 가능한 원인 3가지

#### 원인 A: 백엔드가 분봉 메시지를 보내지 않음 (90% 확률)

**증상**:

- 콘솔에서 `🔍 WebSocket 메시지 수신: { type: 'minute_candle_update', ... }` 로그 없음
- 호가 메시지는 정상 수신되지만 분봉 메시지는 없음

**가능한 이유**:

1. 백엔드의 분봉 집계 로직이 실행되지 않음
2. 백엔드가 장 시간(09:00-15:30 KST)에만 분봉 메시지를 전송
3. 백엔드 실시간 서비스에 버그 또는 오류

**확인 방법**:

```bash
# 백엔드 로그 확인
tail -f backend/logs/app.log | grep -E "minute_candle|분봉"

# 또는 백엔드 콘솔 직접 확인
```

---

#### 원인 B: 종목 구독 메시지가 백엔드에 도달하지 않음 (8% 확률)

**증상**:

- 콘솔에서 `📤 [useRealtimeMinuteCandles] 종목 구독 요청 전송: 005930` 로그 있음
- 하지만 백엔드에서 구독 요청을 받지 못함

**가능한 이유**:

1. WebSocket 메시지 형식 불일치 (백엔드가 `{ type: 'subscribe', stock_code: ... }` 형식을 인식 못함)
2. 백엔드 WebSocket 핸들러에 버그

**확인 방법**:

```python
# 백엔드 WebSocket 핸들러에서 로그 확인
@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    print(f"📥 WebSocket 메시지 수신: {message}")  # 이 로그 추가
```

---

#### 원인 C: Hook 실행 조건 불만족 (2% 확률)

**증상**:

- 콘솔에서 `🔄 [useRealtimeMinuteCandles] 훅 초기화` 로그조차 없음

**가능한 이유**:

1. `enabled === false` (매우 낮은 확률, 코드 분석 결과 `enabled: true`)
2. `timeframe !== 'minute'` (매우 낮은 확률, 코드 분석 결과 `timeframe: 'minute'`)
3. 컴포넌트가 마운트되지 않음 (매우 낮은 확률, 페이지가 정상 표시됨)

**확인 방법**:

