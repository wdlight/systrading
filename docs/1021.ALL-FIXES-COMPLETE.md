## 🔍 이슈 분석 요약

### Backend 이슈 (5개 - 모두 수정 완료)

#### Issue #1: `minute_candle_update` 메시지 스키마 불일치

- **문제**: 문서는 `candle` 필드, 코드는 `data` 필드 사용
- **영향**: Frontend에서 `message.candle` 접근 시 undefined
- **수정**: `data` → `candle`, `is_final: false` 추가

#### Issue #2: `minute_candle_finalize` 타입명 불일치

- **문제**: 문서는 `minute_candle_finalized` (과거분사), 코드는 `minute_candle_finalize`
- **영향**: Frontend 리스너가 메시지를 받지 못함
- **수정**: `minute_candle_finalize` → `minute_candle_finalized`, `data` → `candle`

#### Issue #3: 로그 패턴 불일치

- **문제**: 문서에 명시된 `[MINUTE-FINALIZED]` 로그가 코드에 없음
- **영향**: 모니터링 불가능
- **수정**: `[H0STCNI0-BE]` → `[MINUTE-UPDATE]`, `[MINUTE-FINALIZED]`

#### Issue #4: 지연 체결 데이터 Race Condition

- **문제**: 호가로 새 분봉(14:06) 시작 후 지연된 체결(14:05) 도착 시 시간 역전
- **영향**: 데이터 무결성 손상
- **수정**: `minute_key < state.minute_key` 검증 추가, 과거 데이터 무시

#### Issue #5: Raw 데이터 로깅 부재

- **문제**: 장시간 디버깅을 위한 Raw 데이터 로깅 없음
- **영향**: 버그 재현 및 분석 어려움
- **수정**: 환경 변수 `ENABLE_RAW_HOGA_LOG`, `ENABLE_RAW_TICK_LOG` 추가

### Frontend 이슈 (3개 - 모두 수정 완료)

#### Issue #6: `message.data` 사용으로 인한 Runtime Error

- **문제**: Backend는 `message.candle` 전송, Frontend는 `message.data` 접근
- **영향**: "Cannot read properties of undefined (reading 'timestamp')" 에러
- **우선순위**: 🔴 **CRITICAL** - 즉시 크래시
- **수정**: 모든 `message.data` → `message.candle`

#### Issue #7: `minute_candle_finalize` 타입명 불일치

- **문제**: Frontend 타입/상수가 구 타입명 사용
- **영향**: 분봉 완료 메시지 수신 실패
- **우선순위**: 🔴 **CRITICAL** - 기능 동작 안 함
- **수정**: `finalize` → `finalized` (types.ts, constants.ts, websocket.ts)

#### Issue #8: 문서 상태 표기 오류

- **문제**: "모든 수정 완료" 선언했으나 Frontend 미완료
- **영향**: 혼란 초래
- **우선순위**: 🟡 Medium
- **수정**: 문서 상태를 "Backend + Frontend 완료"로 업데이트

export function subscribeToMinuteCandleFinalized(callback: (message: MinuteCandleFinalizedMessage) => void): () => void {  // ✅ Finalize → Finalized
  console.log('📝 [WS] minute_candle_finalized 리스너 등록');
  const listener = (message: MinuteCandleFinalizedMessage) => {  // ✅

  wsManager.on(WS_MESSAGE_TYPES.MINUTE_CANDLE_FINALIZED, listener);  // ✅
