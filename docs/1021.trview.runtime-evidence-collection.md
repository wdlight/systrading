# 실시간 분봉 미작동 - 런타임 증거 수집 가이드

**문서 ID**: `1021.trview.runtime-evidence-collection.md`
**목적**: 추정이 아닌 **실제 런타임 증거**를 수집하여 정확한 원인 파악
**작성일**: 2025-10-21

---

## ⚠️ 이전 진단의 문제점 (비판 수용)

### 문제 1: 런타임 근거 부재

- ❌ "프론트엔드 코드가 완벽하다" → **실행 여부 미확인**
- ❌ "90% 확률로 백엔드 문제" → **추정치일 뿐, 실측 데이터 없음**
- ❌ "WebSocket 구독 정상" → **실제 구독 호출 확인 안 됨**

### 문제 2: 검증 없는 결론

- 코드 분석만으로 "완벽하게 구현됨"이라 단정
- `useRealtimeMinuteCandles` 훅이 **실제로 실행되는지 확인 안 함**
- subscribe 메시지가 **실제로 전송되는지 확인 안 함**

### 문제 3: 대안 시나리오 배제

- "프론트 조건이 false로 평가" 가능성 무시
- "훅이 마운트되지 않음" 가능성 무시
- 백엔드 책임으로 성급히 결론

---

## 🎯 올바른 진단 절차

### 원칙

1. **코드 분석 ≠ 실행 확인**
2. **추정 < 실측 데이터**
3. **모든 가능성을 배제하지 말고 순차 검증**

### 검증 순서

```
Step 1: Hook 실행 여부 확인 (런타임 증거)
   ↓ 실행 안 됨 → 조건 확인
   ↓ 실행됨
Step 2: 구독 메시지 전송 확인
   ↓ 전송 안 됨 → WebSocket 연결 확인
   ↓ 전송됨
Step 3: 백엔드 메시지 수신 확인
   ↓ 수신 안 됨 → 백엔드 문제
   ↓ 수신됨
Step 4: 데이터 병합/렌더링 확인
```

## 📋 실제 런타임 증거 수집 방법

### 방법 1: 브라우저 콘솔 직접 확인 (가장 정확)

#### 1단계: 페이지 접속

```
1. 브라우저에서 http://localhost:9000/trview 접속
2. F12 (개발자 도구 열기)
3. Console 탭 선택
4. Console settings (톱니바퀴) → "Preserve log" 체크
```

#### 2단계: 필터 설정

```
Console 필터창에 입력:
- "useRealtimeMinuteCandles" (훅 관련 로그만)
- "종목 구독" (구독 관련 로그만)
- "minute_candle" (분봉 메시지만)
- "WebSocket 메시지 수신" (모든 메시지)
```

#### 3단계: 로그 수집 및 스크린샷

**체크리스트**:

```
□ [필수] 전체 콘솔 로그 스크린샷
□ [필수] "useRealtimeMinuteCandles" 검색 결과
□ [필수] "종목 구독 요청" 검색 결과
□ [필수] "minute_candle_update" 검색 결과
□ [필수] "WebSocket 메시지 수신" 검색 결과 (최근 10개)
```

---

### 방법 2: 콘솔 로그 텍스트 복사

#### 전체 로그 복사

```
1. Console에서 Ctrl+A (전체 선택)
2. Ctrl+C (복사)
3. 텍스트 파일에 붙여넣기
4. 파일 공유 또는 일부 발췌
```

#### 필터별 로그 복사

```
# 훅 관련 로그만
Console 필터: "useRealtimeMinuteCandles"
→ 결과 복사

# 구독 관련 로그만
Console 필터: "구독"
→ 결과 복사

# 분봉 메시지만
Console 필터: "minute_candle"
→ 결과 복사
```

## 🔍 예상 시나리오별 증거 패턴

### 시나리오 A: Hook이 실행되지 않음

**예상 로그**:

```
✅ 🔌 [TRViewPage] WebSocket 상태: ...
✅ 📡 [useTRViewChart] fetchData 시작 ...
✅ ✅ [useTRViewChart] 데이터 로드 완료 ...
❌ (useRealtimeMinuteCandles 관련 로그 전혀 없음)
```

**원인**:

- `enabled && isMinuteTimeframe` 조건이 false
- Hook이 조건부로 스킵됨

**다음 단계**:

```typescript
// 페이지에 임시 디버그 로그 추가
console.log('🔍 [DEBUG] useTRViewChart 조건:', {
  enabled: true,
  timeframe: 'minute',
  isMinuteTimeframe: timeframe === 'minute',
  stockCode: '005930'
});
```

---

### 시나리오 B: Hook은 실행되지만 구독 안 됨

**예상 로그**:

```
✅ 🔄 [useRealtimeMinuteCandles] 훅 초기화: stockCode=005930, enabled=true
❌ (종목 구독 요청 전송 로그 없음)
❌ (리스너 등록 로그 없음)
```

**원인**:

- WebSocket 연결 타임아웃
- `wsManager.isConnected()` === false

**다음 단계**:

```typescript
// useRealtimeMinuteCandles.ts에 디버그 추가
console.log('🔍 [DEBUG] WebSocket 연결 상태:', {
  isConnected: wsManager.isConnected(),
  readyState: wsManager.ws?.readyState
});
```

---

### 시나리오 C: 구독은 하지만 메시지 안 옴

**예상 로그**:

```
✅ 🔄 [useRealtimeMinuteCandles] 훅 초기화: stockCode=005930, enabled=true
✅ 📤 [useRealtimeMinuteCandles] 종목 구독 요청 전송: 005930
✅ ✅ [useRealtimeMinuteCandles] 종목 구독 완료: 005930
✅ 📝 [WS] minute_candle_update 리스너 등록
✅ 📝 [WS] minute_candle_finalize 리스너 등록
✅ 🔍 WebSocket 메시지 수신: { type: 'orderbook_update', ... }
✅ 🔍 WebSocket 메시지 수신: { type: 'orderbook_update', ... }
❌ (minute_candle_update 메시지 없음)
```

**원인**:

- 백엔드가 분봉 메시지를 전송하지 않음
- 구독 요청이 백엔드에 도달하지 않음

**다음 단계**:

- 백엔드 로그 확인
- 백엔드 WebSocket 핸들러 확인

---

### 시나리오 D: 메시지는 오지만 차트 업데이트 안 됨

**예상 로그**:

```
✅ 🔄 [useRealtimeMinuteCandles] 훅 초기화: stockCode=005930, enabled=true
✅ 📤 [useRealtimeMinuteCandles] 종목 구독 요청 전송: 005930
✅ 📝 [WS] minute_candle_update 리스너 등록
✅ 🔍 WebSocket 메시지 수신: { type: 'minute_candle_update', ... }
✅ 🔄 [UPDATE] 분봉 업데이트 메시지 수신: ...
✅ ✅ [UPDATE] 분봉 업데이트 처리: 005930 2025-10-21T10:30:00
✅ 🔁 [useTRViewChart] 분봉 merge 결과 { mergedLength: 388 }
❌ (차트가 업데이트되지 않음 - 시각적 확인 필요)
```

**원인**:

- 데이터는 병합되지만 TRViewChart에 전달 안 됨
- React 리렌더링 문제
- chartData props 변경 감지 실패

**다음 단계**:

```typescript
// TRViewChart.tsx에 디버그 추가
useEffect(() => {
  console.log('🔍 [TRViewChart] chartData 변경:', {
    length: chartData.length,
    last: chartData[chartData.length - 1]?.timestamp
  });
}, [chartData]);
```
