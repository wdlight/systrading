## 🔄 4. Key Sequence Diagrams

### 4.1 Mobile FAB + Bottom Sheet Workflow

```mermaid
sequenceDiagram
    actor User
    participant Mobile as Mobile Browser
    participant FAB as FloatingActionButton
    participant BottomSheet as BottomSheet
    participant QuickPanel as QuickActionPanel
    participant FocusTrap as focus-trap-react
    participant LocalStorage as localStorage

    User->>Mobile: 홈페이지 접속
    Mobile->>FAB: 렌더링 (우측 하단)

    User->>FAB: FAB 클릭
    FAB->>BottomSheet: setIsOpen(true)
    BottomSheet->>FocusTrap: 포커스 트랩 활성화
    BottomSheet->>QuickPanel: isSheet={true} 전달
    QuickPanel->>LocalStorage: 마지막 탭 상태 로드
    QuickPanel->>BottomSheet: 탭 콘텐츠 렌더링

    User->>QuickPanel: 종목 선택 (예: 삼성전자)
    QuickPanel->>BottomSheet: onClose() 호출
    BottomSheet->>FocusTrap: 포커스 트랩 해제
    BottomSheet->>Mobile: 원래 포커스 복원
    BottomSheet->>QuickPanel: onStockSelect('005930')
    QuickPanel->>Mobile: 페이지 이동 또는 차트 표시

    User->>BottomSheet: 배경 클릭 또는 스와이프 다운
    BottomSheet->>QuickPanel: 현재 탭 상태 저장
    QuickPanel->>LocalStorage: 탭 상태 persist
    BottomSheet->>BottomSheet: setIsOpen(false)
    BottomSheet->>Mobile: 닫힘 애니메이션
```

### 4.2 UserNotification System Workflow

```mermaid
sequenceDiagram
    actor User
    participant Header as Header Component
    participant NotifCenter as NotificationCenter
    participant LocalStorage as localStorage
    participant Backend as Backend API
    participant WebSocket as WebSocket

    Note over Backend,WebSocket: 매매 체결 발생
    WebSocket->>Backend: 체결 완료 이벤트
    Backend->>WebSocket: UserNotification 전송
    WebSocket->>NotifCenter: 새 알림 수신

    NotifCenter->>NotifCenter: 알림 배열에 추가
    NotifCenter->>LocalStorage: 알림 persist
    NotifCenter->>Header: 뱃지 카운트 증가

    User->>Header: 알림 아이콘 클릭
    Header->>NotifCenter: 알림 센터 열기
    NotifCenter->>LocalStorage: 읽지 않은 알림 로드
    NotifCenter->>User: 알림 목록 표시

    alt 알림 클릭
        User->>NotifCenter: 특정 알림 클릭
        NotifCenter->>NotifCenter: 읽음 상태 업데이트
        NotifCenter->>LocalStorage: persist
        NotifCenter->>NotifCenter: action() 실행
        NotifCenter->>User: 해당 종목 페이지 이동
    else 전체 읽음 처리
        User->>NotifCenter: "모두 읽음" 클릭
        NotifCenter->>NotifCenter: 전체 read: true
        NotifCenter->>LocalStorage: persist
        NotifCenter->>Header: 뱃지 카운트 0
    end
```

## 📝 10. Conclusion & Next Steps

### 10.1 Architecture Highlights

1. **Responsive Design**: 단일 컴포넌트(QuickActionPanel)를 Desktop/Mobile 모두에서 재사용
2. **Data Strategy**:
   - **실제 데이터**: Holdings, Watchlist, Portfolio Summary (WebSocket/API)
   - **Mock 데이터**: UserNotification, Portfolio Chart History (localStorage)
3. **Performance**: localStorage 캐싱으로 빠른 초기 로딩 (차트 히스토리)
4. **Accessibility**: focus-trap-react를 활용한 모달 접근성
