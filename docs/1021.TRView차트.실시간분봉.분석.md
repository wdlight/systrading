# TRView 차트 실시간 분봉 업데이트 분석 보고서

**작성일**: 2025-10-21
**분석 대상**: `/trview` 페이지 분봉 차트 실시간 업데이트 메커니즘
**핵심 이슈**: 호가 정보로부터 실시간 분봉 캔들이 생성되지 않는 문제

---

## 📋 Executive Summary

### 문제 상황
사용자가 `/trview` 페이지에서 분봉 차트를 관찰할 때, **호가(orderbook) 정보가 실시간으로 들어오지만 이를 기반으로 분봉 캔들이 생성되지 않는** 현상이 발생하고 있습니다.

### 근본 원인
**아키텍처 수준의 구조적 문제**: 현재 `/trview` 페이지는 **호가 데이터를 전혀 사용하지 않으며**, 백엔드에서 제공하는 실시간 분봉 WebSocket 메시지(`minute_candle_update`, `minute_candle_finalize`)도 구독하지 않습니다.

### 현재 데이터 흐름
```
백엔드 REST API → useTRViewChart 훅 → TRViewChart 컴포넌트 → lightweight-charts 라이브러리
(정적 데이터만 로드, 실시간 업데이트 없음)
```

### 예상 데이터 흐름 (구현 필요)
```
Option A (백엔드 활용):
백엔드 WebSocket → minute_candle_update 메시지 → useTRViewChart 훅 → TRViewChart.updateCandle() → 실시간 차트 업데이트

Option B (프론트엔드 생성):
백엔드 WebSocket → orderbook_update 메시지 → 호가 데이터 집계 로직 → 분봉 생성 → 실시간 차트 업데이트
```

// useOrderBook.ts (실제 구현 확인 필요)
export function useOrderBook(stockCode: string) {
  const [orderBook, setOrderBook] = useState<OrderBookData | null>(null);

  useEffect(() => {
    const unsubscribe = subscribeToOrderBookUpdates(stockCode, (update) => {
      setOrderBook({
        current_price: update.data.current_price,  // ✅ 현재가
        asks: update.data.asks,
        bids: update.data.bids,
        timestamp: update.data.timestamp,
      });
    });

    return unsubscribe;
  }, [stockCode]);

  return { orderBook };
}

### 4. 문제 진단: 왜 실시간 분봉이 작동하지 않는가?

#### 4.1 아키텍처 격차 (Architecture Gap)

| 구성 요소 | 상태 | 비고 |
|---------|------|------|
| **백엔드 실시간 분봉 시스템** | ✅ 구현됨 | `minute_candle_update`, `minute_candle_finalize` 메시지 브로드캐스트 |
| **WebSocket 구독 함수** | ✅ 구현됨 | `subscribeToMinuteCandles()`, `subscribeToMinuteCandleFinalize()` |
| **실시간 분봉 훅** | ✅ 구현됨 | `useRealtimeMinuteCandles` |
| **차트 실시간 API** | ✅ 구현됨 | `TRViewChart.updateCandle()` |
| **`/trview` 페이지 통합** | ❌ **미구현** | 위 요소들을 연결하는 코드 없음 |

#### 4.2 데이터 플로우 단절

**현재 상태**:
```
[백엔드 실시간 분봉] --X--> [useTRViewChart] --정적 데이터--> [TRViewChart]
                                   ↑
                            REST API (1회만 호출)
```

**필요한 연결**:
```
[백엔드 WebSocket] --minute_candle_update--> [useTRViewChart] --실시간 업데이트--> [TRViewChart.updateCandle()]
```

#### 4.3 호가 데이터 미활용

**호가 데이터로 분봉 생성 가능성**:
- 호가 메시지에 `current_price` 포함 (✅)
- 호가 메시지에 `timestamp` 포함 (✅)
- 1초마다 호가 업데이트 수신 (✅)

**하지만**:
- `/trview` 페이지에서 `useOrderBook` 사용 안 함 (❌)
- 호가 → 분봉 변환 로직 없음 (❌)
- 분 단위 집계 로직 없음 (❌)

- ✅ `useRealtimeMinuteCandles` 훅 재사용 가능
- ✅ 데이터 정합성 보장 (백엔드가 집계)
- ✅ 프론트엔드 복잡도 낮음

**구현 필요 사항**:

1. **`useTRViewChart.ts` 수정**:
```typescript
// ✅ 추가: 실시간 분봉 구독
import { useRealtimeMinuteCandles } from './useRealtimeMinuteCandles';

export function useTRViewChart({ stockCode, timeframe, enabled }: UseTRViewChartProps) {
  const [chartData, setChartData] = useState<ChartCandle[]>([]);

  // 기존: REST API로 초기 데이터 로드
  useEffect(() => {
    fetchData();
  }, [stockCode, timeframe]);

  // ✅ 신규: 실시간 분봉 구독 (분봉만)
  const { currentCandle, finalizedCandles } = useRealtimeMinuteCandles(
    stockCode,
    enabled && timeframe === 'minute'
  );

  // ✅ 신규: 실시간 업데이트 차트 데이터 병합
  const mergedData = useMemo(() => {
    if (timeframe !== 'minute') return chartData;

    // REST 데이터 + 완성된 분봉 + 진행 중인 분봉
    const base = chartData;
    const finalized = finalizedCandles;
    const current = currentCandle ? [currentCandle] : [];

    return mergeCandles(base, finalized, current);
  }, [chartData, finalizedCandles, currentCandle, timeframe]);

  return { chartData: mergedData, ... };
}
```

1. **호가 → 분봉 변환 훅 생성** (`useOrderbookToCandleAggregator.ts`):
```typescript
export function useOrderbookToCandleAggregator(stockCode: string) {
  const [currentMinuteCandle, setCurrentMinuteCandle] = useState<ChartCandle | null>(null);
  const { orderBook } = useOrderBook(stockCode);

  useEffect(() => {
    if (!orderBook) return;

    const { current_price, timestamp } = orderBook;
    const currentMinute = timestamp.substring(0, 16); // "YYYY-MM-DDTHH:mm"

    setCurrentMinuteCandle((prev) => {
      // 새로운 분 시작
      if (!prev || prev.timestamp.substring(0, 16) !== currentMinute) {
        return {
          timestamp: currentMinute + ':00',
          open: current_price,
          high: current_price,
          low: current_price,
          close: current_price,
          volume: 0, // ⚠️ 호가에서 거래량 정보 없음
          // ...
        };
      }

      // 같은 분 내에서 업데이트
      return {
        ...prev,
        high: Math.max(prev.high, current_price),
        low: Math.min(prev.low, current_price),
        close: current_price,
      };
    });
  }, [orderBook]);

  return { currentMinuteCandle };
}
```

2. **`useTRViewChart`에 통합**:
```typescript
const { currentMinuteCandle } = useOrderbookToCandleAggregator(stockCode);

const mergedData = useMemo(() => {
  return mergeCandles(chartData, currentMinuteCandle ? [currentMinuteCandle] : []);
}, [chartData, currentMinuteCandle]);
```

**문제점**:
- ❌ 호가 메시지에 거래량 정보 없음 (추정 불가)
- ❌ 백엔드 분봉과 OHLC 값 불일치 가능
- ❌ 시간대 처리 복잡 (KST vs UTC)

**예상 작업 시간**: 4-6시간

## 🔍 기술적 세부 사항

### 데이터 병합 알고리즘

**현재 문제**:
- REST API 데이터: 과거 ~ 오늘 09:00
- 실시간 데이터: 오늘 09:00 ~ 현재

**병합 전략**:
```typescript
function mergeCandles(
  baseCandles: ChartCandle[],       // REST API
  finalizedCandles: ChartCandle[],  // 완성된 실시간 분봉
  currentCandle: ChartCandle | null // 진행 중인 분봉
): ChartCandle[] {
  // 1. 타임스탬프 기준 Map 생성 (O(n))
  const candleMap = new Map<string, ChartCandle>();

  // 2. 기본 데이터 추가
  baseCandles.forEach(c => {
    const key = c.timestamp.substring(0, 16); // "YYYY-MM-DDTHH:mm"
    candleMap.set(key, c);
  });

  // 3. 완성된 실시간 분봉으로 덮어쓰기 (최신 데이터 우선)
  finalizedCandles.forEach(c => {
    const key = c.timestamp.substring(0, 16);
    candleMap.set(key, c);
  });

  // 4. 진행 중인 분봉 추가
  if (currentCandle) {
    const key = currentCandle.timestamp.substring(0, 16);
    candleMap.set(key, currentCandle);
  }

  // 5. 정렬된 배열 반환
  return Array.from(candleMap.values())
    .sort((a, b) => a.timestamp.localeCompare(b.timestamp));
}
```

**시간 복잡도**: O(n log n) (정렬 때문)
**공간 복잡도**: O(n)

---

### 메모리 관리

**문제**: `finalizedCandles` 배열이 무한정 증가

**해결**: 최대 크기 제한
```typescript
// useRealtimeMinuteCandles.ts 수정
const MAX_FINALIZED_CANDLES = 500; // 약 8시간

setFinalizedCandles((prev) => {
  const updated = [...prev, finalizedCandle];
  return updated.length > MAX_FINALIZED_CANDLES
    ? updated.slice(-MAX_FINALIZED_CANDLES)
    : updated;
});
```

---

### Race Condition 방지

**문제**: 분 경계에서 메시지 순서 뒤바뀜
```
09:15:59 → update(09:15:xx) 전송
09:16:00 → finalize(09:15:xx) 전송
09:16:01 → update(09:15:xx) 도착 (늦은 메시지!)
```

**해결**: 타임스탬프 검증
```typescript
setCurrentCandle((prev) => {
  const prevMin = prev?.timestamp.substring(0, 16);
  const newMin = newCandle.timestamp.substring(0, 16);

  if (prev && newMin < prevMin) {
    console.warn('⚠️ 늦은 업데이트 무시:', newMin);
    return prev; // 최신 상태 유지
  }
  return newCandle;
});
```
