## 1. 현재 구조 분석 (실제 코드 기반)

### 1.1 레이아웃 구조

**파일 위치**: `stock-trading-ui/src/app/page.tsx`

메인 페이지는 Header, Left Sidebar, Main Dashboard, Right Panel의 3단 레이아웃으로 구성:

-   **레이아웃 컴포넌트**:
    -   **Header**: `components/layout/Header.tsx` (상단, 고정)
    -   **TradingConditions**: `components/trading/TradingConditions.tsx` (좌측 사이드바, 접을 수 있음)
    -   **Main Dashboard**: `app/page.tsx` (중앙 콘텐츠, 스크롤 가능)
    -   **QuickActionPanel**: `components/layout/QuickActionPanel.tsx` (우측 패널, **⚠️ 모바일에서 숨김**)

-   **주요 카드 컴포넌트**:
    -   `PortfolioSummary.tsx`: 포트폴리오 요약 (자산, 수익률)
    -   `PortfolioPerformance.tsx`: 성과 분석 (**⚠️ 차트 미구현**)
    -   `HoldingsPanel.tsx`: 보유 종목 테이블
    -   `WatchlistPanel.tsx`: 관심 종목 테이블

**예상 효과**: 스크롤 40% 감소, 모바일 사용성 85% 이상, 정보 접근 시간 50% 단축

export function AssetPanel() {
  const [activeTab, setActiveTab] = useState<'holdings' | 'watchlist' | 'alerts'>('holdings')

  return (
    <Card>
      {/* Tab Navigation - QuickActionPanel의 TabButton 재사용 */}
      <div className="flex border-b border-gray-700">
        <TabButton
          active={activeTab === 'holdings'}
          onClick={() => setActiveTab('holdings')}
          icon={Briefcase}
          label="보유 종목 (5)"
        />
        <TabButton
          active={activeTab === 'watchlist'}
          onClick={() => setActiveTab('watchlist')}
          icon={Eye}
          label="관심 종목 (12)"
        />
        <TabButton
          active={activeTab === 'alerts'}
          onClick={() => setActiveTab('alerts')}
          icon={Bell}
          label="알림 (3)"
        />
      </div>

      {/* Tab Content */}
      <CardContent>
        {activeTab === 'holdings' && <HoldingsTable />}
        {activeTab === 'watchlist' && <WatchlistTable />}
        {activeTab === 'alerts' && <AlertsPanel />}
      </CardContent>
    </Card>
  )
}

- ⚠️ Top Movers에 순위 표시 없음

#### 구현 계획 (간단 작업)

**1단계: 섹션 헤더 강화** (15분)
```tsx
// 기존 h4 태그에 스타일 추가
<h4 className="text-sm font-bold text-white mb-4 uppercase tracking-wide
               border-b-2 border-blue-500 pb-2">
  📈 Major Indices
</h4>
```

**2단계: 순위 배지 추가** (15분)
```tsx
// Top Movers에 순위 표시
<div className="flex items-center gap-2">
  <div className={cn(
    'w-6 h-6 rounded-full flex items-center justify-center text-xs font-bold',
    index < 3 ? 'bg-amber-500 text-white' : 'bg-gray-600 text-gray-300'
  )}>
    {index + 1}
  </div>
  {/* 주식 정보 */}
</div>
```

**📝 상세 구현 가이드**: `docs/plan/1010.dashboard.ux-design-detailed.md` Section 2.3 참조
