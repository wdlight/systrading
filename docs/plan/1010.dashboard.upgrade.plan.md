# 대시보드 UI/UX 개선 계획

**문서 목적**: 현재 대시보드의 UI/UX를 심층 분석하고, 사용성, 정보 접근성, 확장성을 높이기 위한 구체적인 개선 계획을 수립합니다.

## 1. 현재 구조 분석

메인 페이지(`src/app/page.tsx`)는 Header, Left Sidebar, Main Dashboard, Right Panel의 3단 레이아웃으로 구성되어 있습니다. 각 기능은 아래와 같이 모듈화된 컴포넌트로 분리되어 관리되고 있습니다.

-   **레이아웃**:
    -   **Header**: `.../layout/Header.tsx` (상단)
    -   **TradingConditions**: `.../trading/TradingConditions.tsx` (좌측 사이드바)
    -   **Main Dashboard**: `.../app/page.tsx` (중앙 콘텐츠)
    -   **QuickActionPanel**: `.../layout/QuickActionPanel.tsx` (우측 패널)
-   **주요 카드 컴포넌트**:
    -   `PortfolioSummary.tsx`: 포트폴리오 요약
    -   `PortfolioPerformance.tsx`: 성과 분석
    -   `HoldingsPanel.tsx`: 보유 종목
    -   `WatchlistPanel.tsx`: 관심 종목
    -   `MarketOverview.tsx`: 시장 현황

## 3. 상세 개선 방안

### P1: 성과 분석 고도화 (`PortfolioPerformance.tsx`)

-   **1-1. 상호작용 차트 구현 (시급)**
    -   **현황**: 현재 차트 영역이 플레이스홀더로 되어 있어 핵심 기능이 부재합니다.
    -   **개선**: `Recharts` 또는 `Lightweight Charts` 라이브러리를 사용하여 포트폴리오 자산 가치의 시계열 변화(일/주/월)를 시각화하는 꺾은선 그래프를 구현합니다. 차트에는 툴팁, 확대/축소 등 상호작용 기능을 포함합니다.
-   **1-2. 핵심 KPI 및 벤치마크 추가**
    -   **현황**: 단순 수익률만 표시되어 성과에 대한 다각적 평가가 어렵습니다.
    -   **개선**: 차트 상단에 **핵심 KPI(총 손익률, 최대 낙폭(MDD), 변동성)**를 명확히 표시합니다. 또한, KOSPI 등 **벤치마크 지수 추이선을 차트에 함께 표시**하여 상대 성과를 직관적으로 비교할 수 있도록 합니다.

### P2: 패널 통합 및 최적화 (`HoldingsPanel.tsx`, `WatchlistPanel.tsx`)

-   **2-1. 보유/관심 종목 패널 탭 통합**
    -   **현황**: 기능적으로 유사한 두 패널이 분리되어 있어 스크롤이 길어지고 공간 효율이 떨어집니다.
    -   **개선**: 두 패널을 `AssetPanel`과 같은 단일 컴포넌트로 통합하고, 내부에서 **"보유 종목"**과 **"관심 종목"** 탭으로 전환할 수 있도록 UI를 변경합니다. 이를 통해 수직 공간을 절약하고 정보 접근성을 높입니다.
-   **2-2. 테이블 가독성 및 성능 개선**
    -   **현황**: 데이터 로딩 시 전체가 한번에 표시되고, 대용량 데이터 처리 시 성능 저하가 우려됩니다.
    -   **개선**: 데이터 로딩 중에는 **행(Row) 단위 스켈레톤 UI**를 표시하여 사용자가 구조를 미리 인지하게 합니다. API 에러 발생 시 테이블 상단에 **명확한 오류 배너**를 표시합니다. 대용량 목록에 대비하여 `TanStack Table`이나 `react-virtualized`를 활용한 **가상 스크롤(Virtual Scrolling)**을 적용하여 렌더링 성능을 최적화합니다.

### P3: 모바일 사용성 강화 (`QuickActionPanel.tsx`, `Header.tsx`)

-   **3-1. 퀵 액션 패널 모바일 최적화**
    -   **현황**: `QuickActionPanel`이 `xl` 화면 크기 이상에서만 표시되어(`src/app/page.tsx:95`), 모바일에서는 빠른 주문/알림 기능 접근이 불가능합니다.
    -   **개선**: 모바일 화면에서는 하단에 고정된 버튼을 두어 터치 시 **바텀 시트(Bottom Sheet)**나 **슬라이드 오버(Slide-over)** 형태로 `QuickActionPanel`이 나타나도록 구현합니다. 이를 통해 작은 화면에서도 핵심 기능에 즉시 접근할 수 있습니다.
-   **3-2. 헤더 알림 허브 구축**
    -   **현황**: 주문 체결, 조건 만족 등 주요 이벤트 알림 기능이 없습니다.
    -   **개선**: `Header.tsx`의 `Bell` 아이콘에 **실시간 알림 배지**를 추가합니다. 아이콘 클릭 시 `QuickActionPanel`의 '알림' 탭과 연동된 **알림 목록 모달(Modal)이나 토스트(Toast) 메시지**를 표시하여 사용자가 중요한 상태 변화를 놓치지 않도록 합니다.

### P4: 시장 정보 심화 (`MarketOverview.tsx`)

-   **4-1. 제공 정보 다각화**
    -   **현황**: 주요 지수와 등락률 상위 정보만 제공하여 시장 분석에 한계가 있습니다.
    -   **개선**: 카드 내에 탭 또는 필터 기능을 추가하여 **"거래량 상위"**, **"업종별 히트맵"** 등 더 깊이 있는 시장 데이터를 제공합니다.
-   **4-2. 시각적 계층 구조 개선**
    -   **현황**: 섹션 제목과 테이블 간의 간격, 타이포그래피 대비가 부족하여 가독성이 떨어질 수 있습니다.
    -   **개선**: 각 섹션(주요 지수, Top Movers 등)의 구분을 명확히 하고, 제목과 본문 간의 타이포그래피(크기, 굵기) 대비를 강화하여 정보의 위계를 명확하게 만듭니다.

### P5: 레이아웃 유연성 확보

-   **5-1. 동적 그리드 레이아웃 도입**
    -   **현황**: 현재 레이아웃은 정적으로 고정되어 있어 사용자 맞춤화가 불가능합니다.
    -   **개선**: `react-grid-layout`과 같은 라이브러리를 도입하여, 사용자가 **드래그 앤 드롭으로 카드의 위치를 바꾸거나 크기를 조절**할 수 있는 동적 대시보드 기능을 제공합니다. 이를 통해 사용자별로 최적화된 정보 환경을 구축할 수 있습니다.
