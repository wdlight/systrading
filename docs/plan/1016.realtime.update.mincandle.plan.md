# 📈 한국투자증권 OpenAPI 기반 실시간 분봉(OHLC) 구현 가이드

## ✅ 목표
실시간 체결 데이터를 기반으로 분봉(OHLC)을 생성하여  
**TradingView 차트**에 시각화하는 실시간 시스템 구현

---

## 🛠️ 기술 스택

| 구분       | 기술        |
|------------|-------------|
| Backend    | FastAPI (Python) |
| Frontend   | Next.js (React) |
| 차트 도구   | TradingView Charting Library |
| 데이터 소스 | 한국투자증권 OpenAPI (WebSocket + REST) |

---

## 📦 구현 개요

1. **WebSocket**으로 `체결가 (H0STCNT0)` 수신  
2. **FastAPI**에서 체결 데이터를 분 단위로 OHLC 집계  
3. **TradingView**에서 OHLC 데이터를 받아 실시간 차트 렌더링

---

## ✅ 1. WebSocket 체결가 수신

```python
# fastapi_socket.py

import websockets
import asyncio
import json

async def subscribe_to_kiwoom_ws():
    uri = "wss://openapi.koreainvestment.com:9443/websocket"
    headers = {
        "authorization": "Bearer {access_token}",
        "appKey": "your_app_key",
        "appSecret": "your_app_secret"
    }

    async with websockets.connect(uri, extra_headers=headers) as ws:
        await ws.send(json.dumps({
            "tr_id": "H0STCNT0",
            "tr_key": "005930"  # 예: 삼성전자
        }))

        while True:
            msg = await ws.recv()
            await handle_msg(msg)

async def handle_msg(msg):
    fields = msg.split("^")
    price = int(fields[2])  # 현재가
    timestamp = fields[1]   # HHMMSS
    update_minute_ohlc(timestamp, price)


✅ 2. 분봉 OHLC 생성 로직

# fastapi_ohlc_store.py

from datetime import datetime
from collections import defaultdict

ohlc_store = defaultdict(lambda: {"open": None, "high": 0, "low": float("inf"), "close": None})

def update_minute_ohlc(timestamp, price):
    now = datetime.now().strftime('%Y-%m-%d %H:%M')
    ohlc = ohlc_store[now]

    if ohlc["open"] is None:
        ohlc["open"] = price
    ohlc["high"] = max(ohlc["high"], price)
    ohlc["low"] = min(ohlc["low"], price)
    ohlc["close"] = price

import { widget } from '@tradingview/charting_library'
import { useEffect, useRef } from 'react'

export default function TVChart() {
  const chartContainerRef = useRef(null)

  useEffect(() => {
    const widgetOptions = {
      symbol: '005930.KR',
      interval: '1',
      container: chartContainerRef.current,
      library_path: '/static/charting_library/',
      datafeed: {
        onReady: (cb) => cb({ supported_resolutions: ['1', '5', '15'] }),
        getBars: async (symbolInfo, resolution, from, to, onHistoryCallback) => {
          const res = await fetch('http://localhost:8000/ohlc')
          const data = await res.json()
          const bars = Object.entries(data).map(([time, ohlc]) => ({
            time: new Date(time).getTime() / 1000,
            open: ohlc.open,
            high: ohlc.high,
            low: ohlc.low,
            close: ohlc.close,
          }))
          onHistoryCallback(bars, { noData: false })
        },
        subscribeBars: () => {},
        unsubscribeBars: () => {}
      }
    }

    const tvWidget = new widget(widgetOptions)
    return () => tvWidget.remove()
  }, [])

  return <div ref={chartContainerRef} style={{ height: '500px' }} />
}

🔁 실시간 처리 방식

초기에는 FastAPI의 /ohlc를 polling

실시간 반영 시 FastAPI → WebSocket broadcast or SSE(Server Sent Events) 사용 가능

🧠 유의사항

한국투자증권 WebSocket은 ^ 구분자 형식이며 필드는 H0STCNT0 기준

Access Token 만료(1일) 전 갱신 필요

시가/고가/저가/종가는 매 분별로 정확히 초기화/저장 필요

TradingView는 Unix timestamp (초 단위) 사용
