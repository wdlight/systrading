# TRView: 과거 데이터 무한 스크롤 구현 계획

**문서 ID**: `1005.gem.pastdataview.plan.md`
**작성일**: 2025-10-05

## 1. 목표

`TRView` 차트에서 사용자가 차트를 왼쪽으로 스크롤할 때, 이전 날짜의 분봉 데이터를 동적으로 로드하여 보여주는 '무한 스크롤' 기능을 구현한다.

## 2. 핵심 전략

1.  **Hook 중심 로직**: 데이터 로딩, 상태 관리 등 핵심 로직을 `useTRViewChart` 커스텀 훅에 집중시킨다.
2.  **이벤트 기반 트리거**: `lightweight-charts`의 `visibleLogicalRangeChange` 이벤트를 사용하여 사용자의 스크롤 동작을 감지하고 데이터 로드를 트리거한다.
3.  **점진적 데이터 병합**: 새로 로드된 과거 데이터를 기존 차트 데이터의 앞부분에 병합하고, 중복을 제거하여 `setData`로 차트를 업데이트한다.

---

## 3. 파일별 상세 구현 계획

### 3.1. `useTRViewChart.ts` (데이터 관리 허브)

**위치**: `stock-trading-ui/src/hooks/useTRViewChart.ts`

#### 변경 사항:

1.  **상태 추가**:
    *   `isLoadingMore`: `boolean` - 과거 데이터 로딩 상태.
    *   `loadedDates`: `Set<string>` - 중복 날짜 로딩 방지용 Set.
    *   `oldestDate`: `string | null` - 현재 로드된 데이터 중 가장 오래된 날짜를 추적.
    *   `canLoadMore`: `boolean` - 더 로드할 과거 데이터가 있는지 여부.

2.  **함수 추가**:
    *   `loadPreviousDay()`: `oldestDate`를 기준으로 이전 거래일 데이터를 조회하고 `chartData`에 병합하는 비동기 함수.
        *   `isLoadingMore` 플래그를 사용하여 중복 실행 방지.
        *   API로부터 빈 배열 수신 시 (주말, 휴장일 등) 데이터가 나올 때까지 하루씩 더 이전 날짜를 조회하는 로직 포함.
        *   데이터 병합 시 타임스탬프 기준 정렬 및 중복 제거 로직 필수.

3.  **기존 로직 수정**:
    *   초기 데이터 로드(`fetchInitialData`) 시 `oldestDate`, `loadedDates` 상태를 초기화.

4.  **반환 값 추가**:
    *   `loadPreviousDay`
    *   `isLoadingMore`
    *   `canLoadMore`

---

### 3.2. `TRViewChart.tsx` (차트 UI 및 이벤트)

**위치**: `stock-trading-ui/src/components/trading/TRViewChart.tsx`

#### 변경 사항:

1.  **Props 확장**:
    *   `onLoadPrevious?: () => void`: 상위 컴포넌트(`trview/page.tsx`)로부터 `loadPreviousDay` 함수를 전달받을 콜백.
    *   `isLoadingMore?: boolean`: 로딩 인디케이터 표시를 위한 상태.

2.  **이벤트 구독 (useEffect)**:
    *   `chart.timeScale().subscribeVisibleLogicalRangeChange()`를 사용하여 스크롤 이벤트 구독.
    *   핸들러 내에서 `range.from < 10` (차트 왼쪽 끝에 근접)이고 `isLoadingMore`가 `false`일 때 `onLoadPrevious()`를 호출.
    *   컴포넌트 언마운트 시 `unsubscribe` 처리 필수.

3.  **로딩 인디케이터 UI 추가**:
    *   `isLoadingMore` 상태에 따라 차트 좌측 상단에 "이전 데이터 로딩 중..." 텍스트를 표시.
    *   `position: absolute`를 사용하여 차트 위에 오버레이.

---

### 3.3. `trview/page.tsx` (통합 및 상태 연결)

**위치**: `stock-trading-ui/src/app/trview/page.tsx`

#### 변경 사항:

1.  **Hook 사용**:
    *   `useTRViewChart` 훅에서 반환하는 `loadPreviousDay`, `isLoadingMore`를 구조 분해 할당으로 받는다.

2.  **Props 전달**:
    *   `TRViewChart` 컴포넌트에 `onLoadPrevious={loadPreviousDay}`와 `isLoadingMore={isLoadingMore}`를 props로 전달하여 훅과 차트 컴포넌트를 연결한다.

## 4. 주요 기술적 고려사항

*   **주말/휴장일 처리**: `loadPreviousDay` 함수는 API가 빈 데이터를 반환했을 때, 유효한 데이터가 나올 때까지 재귀적으로 또는 루프를 통해 이전 날짜 조회를 시도해야 한다.
*   **데이터 무결성**: 과거 데이터와 현재 데이터를 합칠 때, `Map`과 `sort`를 이용하여 타임스탬프 기준 중복을 완벽히 제거하고 시간 순으로 정렬해야 차트 렌더링 오류를 방지할 수 있다.
*   **이벤트 디바운싱 (Debouncing)**: 사용자의 빠른 스크롤에 의해 이벤트가 과도하게 발생하는 것을 방지하기 위해 `loadPreviousDay` 호출부에 `debounce`를 적용하는 것을 고려한다. (초기 구현에서는 `isLoadingMore` 플래그로 우선 방어)
