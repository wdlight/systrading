# /trview 실시간 분봉 업데이트 실행 계획 (v1.1)

**문서 ID**: `1021.1012.rtupdate.plan.v1.1.md`  
**작성일**: 2025-10-21  
**작성자**: Codex (GPT-5)  
**상태**: 초안

---

## 1. 문제 정의 및 재확인

- `/trview` 페이지의 분봉 차트는 `useTRViewChart` + `TRViewChart` 조합으로 **정적 REST 데이터만** 렌더링한다 (`stock-trading-ui/src/app/trview/page.tsx:152-185`, `stock-trading-ui/src/hooks/useTRViewChart.ts:60-117`).  
- 이미 구현된 실시간 훅(`useRealtimeMinuteCandles`)과 차트(`RealtimeCandlestickChart`)는 다른 화면에서 정상 동작하지만, `/trview`에서는 미사용이다.  
- `OrderForm` 등 주변 기능은 `minuteChartData`를 통해 현재가/과거 데이터를 계산하고 있으므로 단순 교체로는 부작용이 발생한다.

---

## 2. 목표

1. `/trview` 분봉 차트가 WebSocket 기반 실시간 데이터를 반영하도록 한다.  
2. 기존 UI 기능(볼륨/그리드 토글, 과거 데이터 로딩)과 `OrderForm`의 가격 참조가 유지되도록 한다.  
3. 일봉 차트는 기존 REST 흐름을 유지하되, 분봉 흐름과 명확히 구분한다.

---

## 3. 변경 아키텍처 개요

- `useTRViewChart`를 **분봉용/일봉용으로 분리**하거나, 분봉 전용 실시간 훅을 래핑한 `useTRViewMinuteChart`를 신설한다.  
- `TRViewChart`는 일봉 전용으로 사용하며 분봉 UI는 `RealtimeCandlestickChart`를 재사용하되, 필요한 옵션(볼륨/그리드, onLoadPrevious)을 확장한다.  
- 실시간 훅에서 최신 종가를 노출하여 `OrderForm`이 참조할 수 있도록 한다.

---

## 4. 상세 실행 계획

### 4.1 단계 1: 데이터 훅 재구성
- `stock-trading-ui/src/hooks/useTRViewChart.ts`에서 분봉 관련 로직을 분리해 `useTRViewDayChart`로 유지.  
- 새 훅 `useTRViewMinuteRealtime`(가칭) 작성:  
  - 내부에서 `useHistoricalChartData`(또는 기존 REST 호출)를 사용해 초기 데이터 로드.  
  - `useRealtimeMinuteCandles`를 통합해 finalize/update 데이터를 병합.  
  - `currentPrice`(latest close)와 `chartData`를 반환해 `OrderForm`이 활용할 수 있도록 한다.  
  - finalized 캐시 제한, 중복 제거, 종목 전환 초기화 로직 명시.

### 4.2 단계 2: 차트 컴포넌트 조정
- `RealtimeCandlestickChart`에 다음 옵션을 추가하거나 외부에서 처리:  
  - 볼륨/그리드 토글 (`showVolume`, `showGrid`).  
  - 과거 로딩 트리거(`onLoadPrevious`)가 필요하다면 `useHistoricalChartData`를 통해 처리하도록 가이드.  
- `/trview` 분봉 영역을 `RealtimeCandlestickChart`로 교체하고 새 훅에서 반환한 데이터를 전달.

### 4.3 단계 3: `OrderForm` 연계
- `OrderForm` 호출부(`stock-trading-ui/src/app/trview/page.tsx:231-241`)에서 기존 `minuteChartData` 대신 새 훅의 `currentPrice`를 전달.  
- 필요 시 실시간 가격 업데이트를 반영하기 위해 `OrderForm` 내 상태 초기화를 조정.

### 4.4 단계 4: WebSocket 연결 보장
- `/trview`가 `useRealtimeData`를 통해 WebSocket 연결을 이미 공유하는지 확인하고, 의존성이 없다면 페이지 진입 시 `wsManager.connect()`가 실행되도록 상위 레이어 또는 훅에서 호출.  
- 구독/재구독은 `useRealtimeMinuteCandles`가 처리하고 있으므로 추가 액션은 로그 확인으로 충분.

---

## 5. 테스트 계획

1. **실시간 동작**: 1분 경계 전후로 finalize 이벤트가 도착하고 차트/OrderForm 가격이 동기화되는지 확인.  
2. **UI 토글**: 볼륨/그리드 토글이 실시간 차트에서도 정상 작동하는지 확인.  
3. **히스토리 로딩**: 과거 데이터 로딩 트리거(`onLoadPrevious`)가 필요하다면 분봉/일봉 각각에서 확인.  
4. **종목 전환**: 새로운 종목 선택 시 실시간 훅 상태가 초기화되고 finalize 이벤트 수신이 이어지는지 점검.  
5. **WebSocket 재연결**: 브라우저 네트워크 토글로 재연결을 유도해 finalize 이벤트 재구독이 정상 동작하는지 확인.

---

## 6. 리스크 및 대응

- **OrderForm 가격 불일치**: 실시간 훅에서 latest close를 내려주고, 분봉 차트와 동일한 데이터를 사용하도록 보장.  
- **컴포넌트 옵션 차이**: `RealtimeCandlestickChart`에 필요한 prop이 없다면 먼저 확장 구현 후 교체.  
- **테스트 범위 증가**: 실시간 흐름으로 변경되므로 QA 체크리스트를 강화하고, 필요 시 e2e 테스트 추가 검토.

---

## 7. 일정 추정
