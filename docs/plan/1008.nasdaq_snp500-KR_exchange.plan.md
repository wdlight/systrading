✅ 1. NASDAQ / S&P 500 지수 조회 가능 여부
✅ 지원: 가능

한국투자 OpenAPI에서는 해외지수 시세 조회 기능을 지원하고 있으며, FID_COND_MRKT_DIV_CODE = N 조건으로 NASDAQ, S&P 500 등 주요 지수 조회가 가능합니다.

📌 사용 API 예시

해외주식 종목/지수/환율 기간별 시세 조회 API
/uapi/overseas-price/v1/quotations/price-periodic

📌 필수 파라미터 조합 예:
항목	설명	예시
FID_COND_MRKT_DIV_CODE	시장 분류 코드	N (해외지수)
FID_INPUT_ISCD	종목코드	US500, NDX 등
FID_INPUT_DATE_1	조회 시작일	20250101
FID_INPUT_DATE_2	조회 종료일	20251001
FID_PERIOD_DIV_CODE	기간 단위	D (일), W, M, Y 등
✅ 주요 지수 예시코드
지수명	FID_INPUT_ISCD (예시)
NASDAQ 종합	NDX 또는 IXIC (운영 방식 따라 상이)
S&P 500	US500 또는 SPX (공식 포털 종목코드 기준 확인 필요)
✅ 2. 환율 조회 가능 여부
✅ 지원: 가능

한국투자 OpenAPI에서는 KRW/USD 환율을 포함한 다양한 환율에 대해 기간별 시세 조회를 제공합니다.

📌 사용 API 예시

/uapi/overseas-price/v1/quotations/price-periodic (동일 API)

📌 파라미터 조합 예:
항목	설명	예시
FID_COND_MRKT_DIV_CODE	시장 분류 코드	X (환율)
FID_INPUT_ISCD	종목코드	FX@KRW (KRW/USD 환율)
FID_INPUT_DATE_1	조회 시작일	20250101
FID_INPUT_DATE_2	조회 종료일	20251001
FID_PERIOD_DIV_CODE	기간 단위	D (일), W, M, Y 등
🔎 공식 예시 정리
구분	코드 (FID_INPUT_ISCD)	설명
NASDAQ 지수	NDX, IXIC 등	시장 코드 N 사용
S&P 500	US500, SPX 등	시장 코드 N 사용
USD/KRW 환율	FX@KRW	시장 코드 X 사용

📌 개요

한국투자증권 OpenAPI에서는 해외 주요 주가지수(NASDAQ, S&P 500) 및 환율(KRW/USD) 시세를 REST API를 통해 조회할 수 있습니다. 이 문서는 해당 데이터를 조회하는 방법과 주요 파라미터를 정리한 가이드입니다.

✅ 지원 대상
항목	지원 여부	설명
NASDAQ 지수	✅ 지원	NDX 또는 IXIC 코드로 조회 가능
S&P 500 지수	✅ 지원	US500 또는 SPX 코드로 조회 가능
USD/KRW 환율	✅ 지원	FX@KRW 코드로 조회 가능
🔧 사용 API
API 명

🧾 요청 파라미터
파라미터명	설명	필수	예시

FID_INPUT_DATE_1	조회 시작일 (YYYYMMDD)	✅	20250101
FID_INPUT_DATE_2	조회 종료일 (YYYYMMDD)	✅	20251001
FID_PERIOD_DIV_CODE	기간 단위 코드 (D, W, M, Y)	✅	D

GET /uapi/overseas-price/v1/quotations/price-periodic?FID_COND_MRKT_DIV_CODE=N&FID_INPUT_ISCD=US500&FID_INPUT_DATE_1=20250101&FID_INPUT_DATE_2=20251001&FID_PERIOD_DIV_CODE=D

📎 기타 안내

조회 가능한 데이터는 **일별(D), 주별(W), 월별(M), 연별(Y)**로 지정 가능

실시간 데이터가 아닌 기간 시세 조회용 API입니다

NASDAQ/S&P 500 지수는 FID_INPUT_ISCD 값에 따라 조회 성공 여부가 다를 수 있으므로, 복수 코드 테스트를 권장합니다
