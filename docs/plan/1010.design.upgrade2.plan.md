# Dashboard Layout Redesign Plan v2.0 (Single Column)

**문서 버전**: 2.0
**작성일**: 2025-10-10
**Base Document**: [1010.dashboard.upgrade.plan.md v2.4](./1010.dashboard.upgrade.plan.md)
**목적**: Single Column Layout 전환으로 UX 개선 및 Chart Width 최대화

---

## 📋 문서 개요

본 문서는 Dashboard의 레이아웃을 **Single Column** 구조로 전환하는 상세 계획을 다룹니다.

### 주요 목표
1. ✅ **Single Column Layout**: 우측 QuickActionPanel을 유지하면서 메인 콘텐츠를 단일 column으로 재배치
2. ✅ **Chart Width 최대화**: Portfolio Performance Chart를 카드 전체 폭에 맞춰 시각 정보 밀도를 강화
3. ✅ **MarketOverview 최상단**: 컴팩트 뷰로 최소 높이를 유지한 채 최상단에 배치
4. ✅ **Portfolio 카드 통합**: Summary(Compact) + Performance Chart + KPI를 하나의 카드로 묶어 정보 구조 단순화
5. ✅ **Trading Conditions 통합**: 기존 좌측 패널의 매매 조건을 QuickActionPanel `매매` 탭에 흡수하여 상호작용 흐름 일원화

## 🎯 주요 변경 사항

### Before (현재 구조)
```
Row 1: [Portfolio Summary 40%] [Portfolio Performance 60%]
Row 2: [Asset Panel 50%] [Market Overview 50%]

- 총 4개 카드
- 2-column grid
- Market Overview가 하단
- Portfolio Summary/Performance 분리
```

### After (새로운 디자인)
```
Row 1: [Market Overview 100%] - 최소 height (80px)
Row 2: [Portfolio Card 100%] - Summary + Chart 통합 (420px)
       ├─ Summary Compact (60px, 1 row, 개행 없음)
       └─ Chart + KPI (360px, width 100%)
Row 3: [Asset Panel 100%] - Holdings / Watchlist / Alerts 탭 (350px)

Sidebar: [QuickActionPanel] - 고정 (320px, Desktop only), `매매` 탭 내 Trading Conditions 포함

- 총 3개 카드 (통합으로 인해 1개 감소)
- Single column 레이아웃 (메인 영역)
- Market Overview 최상단 컴팩트 뷰
- Portfolio 카드 통합 + Chart 폭 최대화
- Trading 조건/빠른 매매 동선 단일화
- 전체 height: ~850px (2 화면 스크롤)
```

```tsx
  name,
  value,
  change
```

```tsx
// components/trading/PortfolioPerformanceChart.tsx (신규)
'use client';

import { useState, useMemo } from 'react';
import {
  LineChart,
  Line,
  XAxis,
  YAxis,
  CartesianGrid,
  Tooltip,
  ResponsiveContainer,
  Legend
} from 'recharts';
import { cn } from '@/lib/utils';
import { PortfolioTimeRange, PortfolioHistoryPoint } from '@/lib/types';
import { useLocalStorage } from '@/lib/hooks/useLocalStorage';
import { mockPortfolioHistory } from '@/lib/mock/portfolioHistory';

export function PortfolioPerformanceChart() {
  const [timeRange, setTimeRange] = useState<PortfolioTimeRange>('1M');

  // TODO: Replace with real API when /api/portfolio/history is ready
  const [chartData] = useLocalStorage<Record<PortfolioTimeRange, PortfolioHistoryPoint[]>>(
    'portfolioHistory',
    mockPortfolioHistory
  );

  const currentData = useMemo(() => {
    return chartData[timeRange] || [];
  }, [chartData, timeRange]);

  // KPI 계산
  const metrics = useMemo(() => {
    if (currentData.length < 2) {
      return { totalReturn: 0, maxDrawdown: 0, volatility: 0 };
    }

    const firstValue = currentData[0].portfolio;
    const lastValue = currentData[currentData.length - 1].portfolio;
    const totalReturn = ((lastValue - firstValue) / firstValue) * 100;

    // 최대 낙폭 계산
    let maxDrawdown = 0;
    let peak = currentData[0].portfolio;
    currentData.forEach(point => {
      if (point.portfolio > peak) peak = point.portfolio;
      const drawdown = ((point.portfolio - peak) / peak) * 100;
      if (drawdown < maxDrawdown) maxDrawdown = drawdown;
    });

    // 변동성 계산 (단순 표준편차)
    const returns = currentData.slice(1).map((point, i) =>
      ((point.portfolio - currentData[i].portfolio) / currentData[i].portfolio) * 100
    );
    const avgReturn = returns.reduce((a, b) => a + b, 0) / returns.length;
    const variance = returns.reduce((sum, r) => sum + Math.pow(r - avgReturn, 2), 0) / returns.length;
    const volatility = Math.sqrt(variance);

    return { totalReturn, maxDrawdown, volatility };
  }, [currentData]);

  return (
    <div className="space-y-4">
      {/* Header with Time Range Tabs */}
      <div className="flex items-center justify-between">
        <h3 className="text-sm font-semibold text-white">포트폴리오 성과</h3>
        <div className="flex gap-1">
          {(['1D', '1W', '1M', '3M', '6M', '1Y', 'ALL'] as PortfolioTimeRange[]).map((range) => (
            <button
              key={range}
              onClick={() => setTimeRange(range)}
              className={cn(
                'px-3 py-1 text-xs font-medium rounded transition-colors',
                timeRange === range
                  ? 'bg-blue-500/20 text-blue-400 border border-blue-500/30'
                  : 'text-gray-400 hover:text-gray-300 hover:bg-gray-800/50'
              )}
            >
              {range}
            </button>
          ))}
        </div>
      </div>

      {/* Chart (넓은 width, 280px height) */}
      <div className="h-[280px] w-full">
        <ResponsiveContainer width="100%" height="100%">
          <LineChart data={currentData}>
            <CartesianGrid strokeDasharray="3 3" stroke="#374151" />
            <XAxis
              dataKey="date"
              stroke="#9CA3AF"
              tick={{ fill: '#9CA3AF', fontSize: 11 }}
              tickFormatter={(value) => {
                const date = new Date(value);
                return `${date.getMonth() + 1}/${date.getDate()}`;
              }}
            />
            <YAxis
              stroke="#9CA3AF"
              tick={{ fill: '#9CA3AF', fontSize: 11 }}
              tickFormatter={(value) => `${(value / 10000).toFixed(0)}만`}
            />
            <Tooltip
              contentStyle={{
                backgroundColor: '#1f2937',
                border: '1px solid #374151',
                borderRadius: '6px',
                padding: '8px 12px'
              }}
              labelStyle={{ color: '#D1D5DB', fontSize: '12px' }}
              itemStyle={{ fontSize: '12px' }}
              formatter={(value: number) => `${(value / 10000).toFixed(1)}만원`}
            />
            <Legend
              wrapperStyle={{ fontSize: '12px' }}
              iconType="line"
            />
            <Line
              type="monotone"
              dataKey="portfolio"
              stroke="#3B82F6"
              strokeWidth={2}
              dot={false}
              name="포트폴리오"
              animationDuration={300}
            />
            <Line
              type="monotone"
              dataKey="benchmark"
              stroke="#6B7280"
              strokeWidth={1}
              strokeDasharray="5 5"
              dot={false}
              name="KOSPI"
              animationDuration={300}
            />
          </LineChart>
        </ResponsiveContainer>
      </div>

      {/* KPI Cards */}
      <div className="grid grid-cols-3 gap-4">
        <KPICard
          label="총 수익률"
          value={`${metrics.totalReturn >= 0 ? '+' : ''}${metrics.totalReturn.toFixed(2)}%`}
          trend={metrics.totalReturn >= 0 ? 'up' : 'down'}
          icon="📈"
        />
        <KPICard
          label="최대 낙폭"
          value={`${metrics.maxDrawdown.toFixed(2)}%`}
          trend="neutral"
          icon="📉"
        />
        <KPICard
          label="변동성"
          value={`${metrics.volatility.toFixed(2)}%`}
          trend="neutral"
          icon="📊"
        />
      </div>
    </div>
  );
}

// KPI Card Component
function KPICard({
  label,
  value,
  trend,
  icon
}: {
  label: string;
  value: string;
  trend: 'up' | 'down' | 'neutral';
  icon: string;
}) {
  return (
    <div className="rounded-lg border border-gray-700 bg-[#1a1a1a] p-3">
      <div className="flex items-center gap-2 mb-1">
        <span className="text-lg">{icon}</span>
        <span className="text-xs text-gray-400">{label}</span>
      </div>
      <div className={cn(
        'text-lg font-bold',
        trend === 'up' && 'text-profit-foreground',
        trend === 'down' && 'text-loss-foreground',
        trend === 'neutral' && 'text-white'
      )}>
        {value}
      </div>
    </div>
  );
}
```

```tsx
import { PortfolioTimeRange, PortfolioHistoryPoint } from '@/lib/types';

// Helper function to generate mock data
function generatePortfolioHistory(days: number): PortfolioHistoryPoint[] {
  const data: PortfolioHistoryPoint[] = [];
  const baseValue = 10000000; // 1천만원
  const baseIndex = 2500; // KOSPI 기준

  for (let i = 0; i < days; i++) {
    const date = new Date();
    date.setDate(date.getDate() - (days - i - 1));

    // 랜덤 변동 (-2% ~ +2%)
    const portfolioChange = (Math.random() - 0.5) * 0.04;
    const benchmarkChange = (Math.random() - 0.5) * 0.03;

    const prevPortfolio = i === 0 ? baseValue : data[i - 1].portfolio;
    const prevBenchmark = i === 0 ? baseIndex : data[i - 1].benchmark;

    data.push({
      date: date.toISOString().split('T')[0],
      portfolio: prevPortfolio * (1 + portfolioChange),
      benchmark: prevBenchmark * (1 + benchmarkChange),
    });
  }

  return data;
}
```

```tsx
// lib/featureFlags.ts
export const FEATURE_FLAGS = {
  NEW_SINGLE_COLUMN_LAYOUT: process.env.NEXT_PUBLIC_FF_SINGLE_COLUMN === 'true',
} as const;

// app/page.tsx
import { FEATURE_FLAGS } from '@/lib/featureFlags';

export default function Home() {
  if (FEATURE_FLAGS.NEW_SINGLE_COLUMN_LAYOUT) {
    return <NewSingleColumnLayout />;
  }
  return <LegacyLayout />;
}
```

#### Option 2: 직접 교체
```bash
# 1. 기존 코드 백업
git checkout -b backup/old-layout

# 2. 새로운 레이아웃 구현
git checkout feature/trade
# Phase 1-4 구현

# 3. 테스트 후 배포
npm run build
npm run start

# 4. 문제 발생 시 롤백
git revert <commit-hash>
```
