# 분봉 차트 실시간 업데이트 구현 계획 (폴링 방식)

## 📊 현황 분석

### 현재 분봉 데이터 처리 흐름

1. **데이터 저장**: `ChartCacheService`가 `kordata/{종목코드}/{YYYYMMDD}.json` 형식으로 분봉 데이터를 로컬 저장
2. **데이터 조회**: `TradingService.get_minute_chart_data()` → `ChartCacheService.get_minute_candles()`
3. **캐시 전략**: 

            - 오늘 데이터: 실시간 API 호출 + Gap-fill 로직
            - 과거 데이터: 로컬 캐시 우선, 없으면 API 호출

4. **문제점**: 프론트엔드가 수동으로 새로고침해야 하며, 실시간성 부족

### 백엔드 캐시 상황

- **위치**: `kordata/{종목코드}/{YYYYMMDD}.json`
- **업데이트**: API 호출 시마다 최신 데이터로 갱신
- **장점**: 이미 구축된 안정적인 캐시 인프라
- **활용**: 체결 데이터가 백그라운드에서 누적되고 있음 (WebSocket H0STCNT0)

## 🎯 제안 방안: 폴링 기반 캐시 데이터 활용

**핵심 아이디어**: 프론트엔드에서 짧은 주기(5-10초)로 백엔드에 분봉 데이터 요청 → 백엔드는 캐시 우선 응답, 캐시 미스 시 한투 API 호출

**장점**:

- ✅ **구현 간단**: 기존 API 재활용, 최소 수정
- ✅ **재활용성 높음**: 일봉, 주봉 등 다른 차트에도 동일 패턴 적용 가능
- ✅ **안정성**: WebSocket 연결 상태와 무관하게 동작
- ✅ **캐시 효율**: 백엔드 캐시로 한투 API 트래픽 최소화
- ✅ **디버깅 용이**: HTTP API로 명확한 요청/응답 추적

**단점**:

- 실시간성 약간 떨어짐 (5-10초 지연)
- 폴링 트래픽 발생 (하지만 캐시로 최소화)

### Phase 1: 백엔드 - 분봉 데이터 API 최적화

**파일**: `backend/app/services/chart_cache_service.py`

**목표**:

- 캐시 미스 시 한투 API 호출하여 최신 데이터 반영
- 메모리 캐시 추가로 반복 요청 최적화

**수정 위치**: `get_minute_candles` 메서드에 메모리 캐시 추가

```python
class ChartCacheService:
    def __init__(self, cache_dir: str = "kordata"):
        self.cache_dir = Path(cache_dir)
        self._ensure_cache_dir()
        
        # ✅ 추가: 메모리 캐시 (최근 조회한 데이터)
        self.memory_cache: Dict[str, Tuple[datetime, List[ChartCandle]]] = {}
        self.memory_cache_ttl = 5  # 5초 TTL
    
    async def get_minute_candles(
        self,
        stock_code: str,
        target_date: datetime,
        korea_invest_service
    ) -> List[ChartCandle]:
        """
        분봉 데이터 조회 (메모리 캐시 → 파일 캐시 → API 호출)
        """
        now = datetime.now()
        cache_key = f"{stock_code}_{target_date.strftime('%Y%m%d')}"
        
        # ✅ Step 1: 메모리 캐시 확인 (5초 이내)
        if cache_key in self.memory_cache:
            cached_time, cached_data = self.memory_cache[cache_key]
            if (now - cached_time).total_seconds() < self.memory_cache_ttl:
                logger.debug(f"메모리 캐시 히트: {cache_key}")
                return cached_data
        
        # ✅ Step 2: 파일 캐시 확인
        cached_data = self._load_from_cache(stock_code, target_date)
        
        # ✅ Step 3: 캐시 미스 시 API 호출
        if not cached_data:
            logger.info(f"캐시 미스: {cache_key}, API 호출")
            cached_data = await self._fetch_full_day_candles(
                stock_code=stock_code,
                target_date=target_date,
                korea_invest_service=korea_invest_service
            )
            
            if cached_data:
                self._save_to_cache(stock_code, target_date, cached_data)
        
        # ✅ Step 4: 메모리 캐시 갱신
        if cached_data:
            self.memory_cache[cache_key] = (now, cached_data)
            
            # 메모리 캐시 크기 제한 (최대 20개)
            if len(self.memory_cache) > 20:
                oldest_key = min(self.memory_cache.keys(), 
                                key=lambda k: self.memory_cache[k][0])
                del self.memory_cache[oldest_key]
        
        return cached_data or []
```

```python
@router.get("/minute/{stock_code}")
async def get_minute_chart(
    stock_code: str,
    date: Optional[str] = None,  # YYYY-MM-DD 형식
    trading_service: TradingService = Depends(get_trading_service)
):
    """
    분봉 차트 데이터 조회 (캐시 우선, 미스 시 API 호출)
    
 - 5초 메모리 캐시로 반복 요청 최적화
 - 파일 캐시로 한투 API 트래픽 최소화
    """
    try:
        target_date = datetime.strptime(date, "%Y-%m-%d") if date else datetime.now()
        
        candles = await trading_service.get_minute_chart_data(
            stock_code=stock_code,
            target_date=target_date,
            regular_hours_only=True
        )
        
        return {
            "success": True,
            "data": [candle.dict() for candle in (candles or [])],
            "cached": True,  # 캐시 히트 여부 (선택)
            "timestamp": datetime.now().isoformat()
        }
    except Exception as e:
        logger.error(f"분봉 조회 실패: {stock_code}, {e}")
        raise HTTPException(status_code=500, detail=str(e))
```

### Phase 4: 백엔드 - 백그라운드 캐시 워밍 (선택)

**파일**: `backend/app/services/realtime_service.py`

**목표**: 체결 데이터 수신 시 자동으로 분봉 캐시 업데이트

```python
async def _handle_tick_data(self, message: Dict[str, Any]):
    """체결 데이터 처리 + 분봉 캐시 워밍"""
    try:
        data = message.get('data', {})
        stock_code = data.get('종목코드')
        
        # 기존 로직 유지
        if '현재가' not in data:
            return
        
        current_price_str = data.get('현재가')
        current_price = float(current_price_str.replace(",", "")) if current_price_str else 0
        
        if stock_code in self.realtime_watchlist_df.index:
            self.realtime_watchlist_df.loc[stock_code, "현재가"] = current_price
            
            await self.connection_manager.broadcast({
                "type": "tick_update",
                "stock_code": stock_code,
                "current_price": current_price,
                "timestamp": datetime.now().isoformat()
            })
        
        # ✅ 추가: 분봉 캐시 워밍 (1분마다 한 번만)
        now = datetime.now()
        cache_key = f"{stock_code}_{now.strftime('%Y%m%d_%H%M')}"
        
        if not hasattr(self, '_last_cache_warm') or cache_key not in self._last_cache_warm:
            if not hasattr(self, '_last_cache_warm'):
                self._last_cache_warm = {}
            
            # 분봉 캐시에 현재가 반영 (비동기, 에러 무시)
            try:
                # ChartCacheService에 현재 체결 데이터 추가
                # 이 부분은 선택적이며, 필요시 구현
                logger.debug(f"분봉 캐시 워밍: {stock_code}")
            except:
                pass
            
            self._last_cache_warm[cache_key] = now
            
            # 오래된 키 정리 (메모리 관리)
            if len(self._last_cache_warm) > 100:
                oldest_key = min(self._last_cache_warm.keys(),
                               key=lambda k: self._last_cache_warm[k])
                del self._last_cache_warm[oldest_key]
        
    except Exception as e:
        logger.error(f"체결 데이터 처리 오류: {e}")
```
