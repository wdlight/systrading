### Phase 1: Backend API 개발

#### 1.1 주문 API 엔드포인트 생성 (`backend/app/api/orders.py`)

```python
# 새로운 라우터 생성
POST   /api/orders/buy          # 매수 주문
POST   /api/orders/sell         # 매도 주문
POST   /api/orders/modify       # 주문 정정
DELETE /api/orders/cancel       # 주문 취소
GET    /api/orders/pending      # 미체결 주문 조회
GET    /api/orders/history      # 체결 내역 조회
```

**데이터 모델** (`backend/app/models/order_models.py`):
```python
class OrderRequest(BaseModel):
    stock_code: str          # 종목코드
    stock_name: str          # 종목명
    order_type: str          # "00"(지정가), "01"(시장가)
    order_side: str          # "buy"(매수), "sell"(매도)
    quantity: int            # 주문수량
    price: Optional[int]     # 주문가격 (시장가는 0)

class OrderResponse(BaseModel):
    order_number: str        # 주문번호
    status: str             # 접수/체결/거부
    message: str            # 응답 메시지
```

#### 1.2 주문 서비스 로직 (`backend/app/services/order_service.py`)

```python
class OrderService:
    async def place_buy_order()    # 매수 주문 실행
    async def place_sell_order()   # 매도 주문 실행
    async def modify_order()       # 주문 정정
    async def cancel_order()       # 주문 취소
    async def get_pending_orders() # 미체결 조회
    async def get_order_history()  # 체결 내역
```

## 📝 참고사항

- **한국투자증권 API 문서**: 주문 유형 코드 확인 필요
  - `00`: 지정가
  - `01`: 시장가
  - `02`: 조건부지정가
  - `03`: 최유리지정가
  - `04`: 최우선지정가
- **호가 단위**: 종목별 호가 단위 자동 적용
  - 1,000원 미만: 1원
  - 1,000원 ~ 5,000원: 5원
  - 5,000원 ~ 10,000원: 10원
  - 10,000원 ~ 50,000원: 50원
  - 50,000원 이상: 100원
- **주문 시간**: 장 운영 시간 확인 필요
  - 정규 장: 09:00 ~ 15:30
  - 시간외 단일가: 08:30 ~ 09:00, 15:40 ~ 16:00
- **모의투자**: KI_IS_PAPER_TRADING 설정 확인
