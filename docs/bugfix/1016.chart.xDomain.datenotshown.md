# 일봉 차트 X축 날짜 표시 형식 수정 플랜

## 1. 문제 분석

### 현재 상황

- **파일**: `stock-trading-ui/src/app/trview/page.tsx`
- 분봉 차트와 일봉 차트를 동시에 표시
- 분봉: `timeframe="minute"` → X축에 HH:MM 표시 필요
- 일봉: `timeframe="day"` → X축에 MM/DD 표시 필요

### 문제 원인

1. **chartConfig.ts (44-53번 라인)**
   ```typescript
   tickMarkFormatter: (time: UTCTimestamp) => {
     const date = new Date(time * 1000);
     return new Intl.DateTimeFormat('ko-KR', {
       hour: '2-digit',
       minute: '2-digit',
       hour12: false,
       timeZone: 'Asia/Seoul',
     }).format(date);
   }
   ```


   - 하드코딩된 시:분 포맷만 사용
   - `timeframe` 파라미터를 받지 않음

2. **TRViewChart.tsx (180-203번 라인)**
   ```typescript
   chartRef.current.timeScale().applyOptions({
     timeVisible: !isDay,
     secondsVisible: false,
     // tickMarkFormatter는 주석 처리됨
   });
   ```


   - `tickMarkFormatter` 동적 변경 로직이 주석 처리됨
   - TypeScript 타입 문제로 비활성화된 것으로 보임

### lightweight-charts의 시간 포맷 지원

- `timeScale().applyOptions()`에서 `timeVisible`, `secondsVisible` 설정 가능
- `tickMarkFormatter`는 **초기 차트 생성 시**에만 설정 가능 (동적 변경 불가)
- 해결책: `timeframe`에 따라 차트 생성 시점에 올바른 포맷터 전달

## 2. 구현 계획

### Phase 1: chartConfig.ts 수정

**파일**: `stock-trading-ui/src/lib/tradingview/chartConfig.ts`

#### 변경 사항

```typescript
// 기존 함수 시그니처 변경
export function getTRViewChartOptions(
  timeframe: 'minute' | 'day' = 'minute'
): DeepPartial<ChartOptions>
```

#### tickMarkFormatter 로직

```typescript
timeScale: {
  borderColor: '#374151',
  timeVisible: true,
  secondsVisible: false,
  tickMarkFormatter: (time: UTCTimestamp) => {
    const date = new Date(time * 1000);
    
    if (timeframe === 'day') {
      // 일봉: MM/DD 형식
      return new Intl.DateTimeFormat('ko-KR', {
        month: '2-digit',
        day: '2-digit',
        timeZone: 'Asia/Seoul',
      }).format(date).replace('. ', '/').replace('.', '');
      // "10. 15." → "10/15"
    } else {
      // 분봉: HH:MM 형식
      return new Intl.DateTimeFormat('ko-KR', {
        hour: '2-digit',
        minute: '2-digit',
        hour12: false,
        timeZone: 'Asia/Seoul',
      }).format(date);
    }
  },
}
```

### Phase 2: TRViewChart.tsx 수정

#### 변경 위치 2: localization timeFormatter (91-102번 라인)

```typescript
chart.applyOptions({
  localization: {
    timeFormatter: (timestamp: number) => {
      const date = new Date(timestamp * 1000);
      
      if (timeframe === 'day') {
        // 일봉: YYYY-MM-DD 형식 (툴팁/범례용)
        return formatKST(date, {
          year: 'numeric',
          month: '2-digit',
          day: '2-digit',
        });

        // 분봉: YYYY-MM-DD HH:MM 형식
        return formatKST(date, {
          year: 'numeric',
          month: '2-digit',
          day: '2-digit',
          hour: '2-digit',
          minute: '2-digit',
        });
      }
    },
  },
});
```

## 3. 테스트 계획

### 수동 테스트

1. `/trview` 페이지 접속
2. **분봉 차트 확인**:

   - X축에 `09:30`, `10:00`, `10:30` 등 시:분 형식 표시
   - 크로스헤어 이동 시 툴팁에 전체 날짜/시간 표시

3. **일봉 차트 확인**:

   - X축에 `10/01`, `10/02`, `10/03` 등 월/일 형식 표시
   - 크로스헤어 이동 시 툴팁에 날짜만 표시

### 엣지 케이스

- 연도가 바뀌는 경우 (12/31 → 01/01): 월/일만 표시되므로 문제없음
- 장 시작/종료 시간대: 분봉에서 정확한 시간 표시 확인
- 데이터 부족 시: 빈 차트에서도 축 레이블 정상 표시

## 5. 기술적 고려사항

### lightweight-charts의 제약사항

- `tickMarkFormatter`는 차트 생성 시에만 설정 가능
- 런타임에 동적으로 변경하려면 차트를 재생성해야 함
- 따라서 `timeframe`을 useEffect 의존성에 추가하여 변경 시 차트 재생성

### 한국 날짜 포맷

```typescript
// Intl.DateTimeFormat 출력 예시
// month: '2-digit', day: '2-digit' → "10. 15."
// .replace('. ', '/').replace('.', '') → "10/15"
```

### 성능 영향

- `timeframe` 변경 시 차트 재생성으로 약간의 깜빡임 발생 가능
- 하지만 사용자가 분봉/일봉을 자주 전환하지 않으므로 문제없음
- 현재 구현에서는 두 차트가 별도 컴포넌트이므로 영향 없음
