# 차트 데이터 로딩 및 렌더링 이슈 해결 (2025-10-03)

## 1. 이슈 요약

사용자에 의해 제기된 차트 관련 이슈들은 다음과 같으며, 모두 상호 연관되어 있음이 밝혀졌다.

1.  **데이터 불일치**: 특정 날짜(예: 10월 1일)를 조회했을 때, 백엔드 원본 데이터와 다른 엉뚱한 시간대의 데이터가 표시됨. (예: 9시 데이터 누락)
2.  **시간 축 눈금 오류**: X축의 시간 간격이 30분으로 설정했음에도 1시간 또는 15분으로 표시되고, 드래그 시 간격이 바뀌는 등 불안정하게 동작함.
3.  **비거래 시간 공백**: 장 마감(15:30)과 다음 날 장 시작(09:00) 사이의 비거래 시간이 차트 상에 빈 공간으로 표시되어 데이터 가독성을 해침.
4.  **차트 간격 축소**: 날짜가 바뀌는 구간을 드래그하면, 비거래 시간 공백 때문에 차트가 급격히 좁아지는 현상 발생.

---

## 2. 근본 원인 분석

### 2.1. 데이터 불일치 원인: 시간대(Timezone) 버그 및 잘못된 훅(Hook) 사용

- **초기 원인 (시간대 버그)**: 프론트엔드에서 "오늘 날짜"를 계산할 때 `new Date().toISOString()`을 사용하여 UTC 기준으로 날짜를 계산하는 것이 원인이었다. 이로 인해 한국 시간 기준 새벽 0시~9시 사이에 접속 시, 하루 전 데이터를 요청하는 버그가 발생했다.
- **핵심 원인 (잘못된 훅 사용)**: `test-chart` 페이지의 요구사항은 **"이전 3일치 데이터 표시"**이지만, 실제로는 **"오늘 하루치 데이터"**를 불러오는 `useRealChartData` 훅을 사용하고 있었다. 정작 3일치 데이터를 불러오는 로직을 가진 `useHistoricalChartData` 훅은 데이터가 외부에서 주입된다는 이유로 비활성화되고 있었다.

### 2.2. 렌더링 오류 원인: 연속적인 시간 축 사용

- **원인**: 차트 라이브러리(`recharts`)가 X축을 연속적인 시간 흐름으로 간주하고 렌더링하는 것이 문제의 원인이다.
- **영향**: 주식 데이터는 비거래 시간으로 인해 비연속적이다. 이 불일치로 인해 차트 라이브러리는 비거래 시간까지 모두 포함하여 축을 계산하게 되고, 이는 의도치 않은 공백(Gap), 차트 좁아짐, 눈금 계산 오류로 이어졌다.

## 3. 해결 진행 과정

사용자의 "작은 단위로 나누어 진행" 요청에 따라, 여러 단계에 걸쳐 원인을 분석하고 수정했다.

### **1단계: 시간대 버그 분석 및 1차 수정**

- **진행 내용**: 시간대 버그를 해결하기 위해 KST 기준 날짜 유틸리티(`datetime.ts`)를 생성하고, `useHistoricalChartData.ts`에 적용했다.
- **결과**: 데이터가 여전히 잘못 표시됨을 확인. 수정한 파일이 현재 페이지에서 사용되지 않음을 인지했다.

### **2단계: 근본 원인 재규명**

- **진행 내용**: 코드 흐름을 재추적한 결과, `test-chart` 페이지가 `useRealChartData` 훅을 사용하고 있음을 최종적으로 밝혀냈다.
- **결론**: 페이지의 요구사항(3일치 데이터)과 실제 사용되는 데이터 로딩 로직(1일치 데이터)이 서로 다르다는 점을 확정했다.

### **3단계: 아키텍처 재검토 및 계획 수정**

- **진행 내용**: `KoreanTradingChart` 컴포넌트의 사용처를 전수조사한 결과, 메인 거래 페이지(`/korean-trading`)에서도 사용 중임을 발견했다.
- **분석**: 메인 페이지는 이 컴포넌트를 **일봉(`D`) 차트** 용도로 사용하고 있었다. 따라서 데이터 로딩 흐름을 섣불리 변경할 경우, 메인 페이지의 차트가 깨질 위험이 있음을 확인했다.
- **결론**: 아키텍처 변경의 위험성을 고려하여, 여러 컴포넌트의 데이터 흐름을 바꾸는 대신, 현재 사용되고 있는 `useRealChartData` 훅의 기본 동작을 직접 수정하는 것이 가장 안전하고 효율적인 방법이라고 최종 판단했다.

## 4. 최종 해결 계획 (수정됨)

### **1단계: 데이터 로딩 로직 수정 (예정)**

- **목표**: `useRealChartData` 훅이 기본적으로 **"최근 3일치 데이터"**를 불러오도록 수정하여, 사용자의 요구사항을 만족시키고 데이터 불일치 문제를 해결한다.
- **작업 내용**: `useRealChartData.ts` 파일의 `fetchChartData` 함수 내부 로직을 수정한다. 날짜가 지정되지 않았을 경우, 오늘 하루가 아닌 최근 3일치 데이터를 조회하도록 변경한다.
- **기대 효과**: 데이터가 KST 기준으로 정확히 로드되고, 9시 데이터 누락 문제가 해결된다. 이 수정은 `test-chart` 페이지에만 영향을 미치고, `timeframe`이 'D'로 설정된 메인 페이지에는 영향을 주지 않는다.

### **2단계: 인덱스 기반 X축 도입 (예정)**

- **목표**: 데이터 로딩 문제가 해결된 후, 남아있는 모든 렌더링 문제(비거래 시간 공백, 눈금 오류, 차트 좁아짐)를 근본적으로 해결한다.
- **작업 내용**: `RechartsAdapter.tsx`의 X축을 시간 기반에서 데이터 순서(인덱스) 기반으로 변경하는 리팩토링을 진행한다.
- **기대 효과**: 비연속적인 주식 데이터를 문제없이 처리하고, 일관되고 안정적인 차트 렌더링을 보장한다.
