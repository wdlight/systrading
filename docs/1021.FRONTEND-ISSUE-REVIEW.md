### 이슈 #6: Frontend에서 `message.data` 사용 (Runtime Error 발생)

**지적 내용**:
- `useRealtimeMinuteCandles.ts:71`에서 `message.data`를 사용
- Backend는 이제 `candle` 필드로 전송
- `data`는 `undefined`가 되어 "Cannot read properties of undefined" 오류 발생

**검증 결과**:

**Frontend 코드** (`useRealtimeMinuteCandles.ts:71-79`):
```typescript
console.log(`✅ [UPDATE] 분봉 업데이트 처리: ${message.stock_code} ${message.data.timestamp}`);
const { data } = message;  // ❌ Backend는 "candle" 필드로 보냄
setCurrentCandle({
  timestamp: data.timestamp,  // ❌ data는 undefined
  open: data.open,
  high: data.high,
  low: data.low,
  close: data.close,
  volume: data.volume,
  // ...
});
```

**Backend 전송 메시지** (수정 후):
```python
payload = {
    "type": "minute_candle_update",
    "stock_code": stock_code,
    "candle": {  # ✅ "candle" 필드
        "timestamp": state.minute_key,
        "open": state.open,
        # ...
    },
    "is_final": False
}
```

**판단**: ✅ **지적 사항 수용 - 치명적 버그**
- `message.data`는 `undefined`
- 즉시 Runtime Error 발생
- **수정 필수**: `message.data` → `message.candle`
