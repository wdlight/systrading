## 🔍 추가 개선 여지

### 현재 이슈
API가 `start_time=133600`으로 호출했지만:
- **수집된 데이터**: 65개 (13:36부터 역순으로 10 batch)
- **실제 필요**: 11개 (13:36~13:46만)

**원인**: `get_minute_chart_data()` 메서드가 배치 단위로 역순 수집 중

### 제안 개선사항
1. **Max count 파라미터 활용**: Gap 크기 계산 → `max_count` 지정
   ```python
   gap_minutes = (now - latest_time).seconds / 60
   gap_candles = await korea_invest_service.get_minute_chart_data_from(
       stock_code=stock_code,
       start_time=gap_start_hhmmss,
       max_count=int(gap_minutes) + 5  # 여유분 5개
   )
   ```

2. **조기 중단 로직**: `start_time`에 도달하면 루프 중단
   ```python
   # ki_api.py에서
   if 현재_배치_최소시간 < start_time:
       break  # start_time 이전 데이터는 불필요
   ```
