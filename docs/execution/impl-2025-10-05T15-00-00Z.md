# 작업 기록: UI 개선, 차트 기능 구현 및 버그 수정

**문서 ID**: `impl-2025-10-05T15-00-00Z.md`

## 1. 개요

본 문서는 TRView 페이지의 UI 버그 수정, 신규 기능(일봉/분봉 동시 조회, OHLC 정보창) 구현, 그리고 그 과정에서 발생한 다수의 프론트엔드 및 백엔드 에러를 해결한 내역을 기록합니다.

---

## 2. 주요 작업 내역

### 2.1. UI 개선 및 버그 수정

- **종목 검색창 포커스 테두리 제거**
  - **현상**: 종목 검색창 클릭 시 흰색 테두리가 표시되어 다크 테마 UI와 어울리지 않음.
  - **조치**: `outline-hidden`으로 잘못 작성된 CSS 클래스를 `outline-none`으로 수정.
  - **영향 받은 파일**: `stock-trading-ui/src/components/ui/command.tsx`

- **일봉 차트 X축 포맷 수정**
  - **현상**: 일봉 차트의 X축에 날짜 대신 시간("00:00")이 표시됨.
  - **조치**: `TRViewChart.tsx`에 `timeframe` prop을 추가하고, `tickMarkFormatter`를 사용하여 `timeframe`이 'day'일 경우 X축 라벨을 `YYYY-MM-DD` 형식으로 강제 변환.
  - **영향 받은 파일**: `stock-trading-ui/src/components/trading/TRViewChart.tsx`, `stock-trading-ui/src/app/trview/page.tsx`

### 2.2. 신규 기능 구현

- **일봉/분봉 차트 동시 조회 기능**
  - **요구사항**: 기존의 단일 차트 화면을 분봉(상단)과 일봉(하단) 차트가 동시에 표시되는 구조로 변경.
  - **백엔드 구현**:
    - `korea_invest.py`: `get_daily_price_chart`가 반환하는 `DataFrame`을 `List[ChartCandle]`로 변환하는 `get_daily_chart_data` 헬퍼 메소드 추가.
    - `chart_cache_service.py`: 일봉 데이터를 연도별로 JSON 파일에 캐싱하는 `get_daily_candles` 메소드 추가.
    - `trading_service.py`: 서비스 레이어에 `get_day_chart_data` 메소드 추가.
    - `chart.py`: 프론트엔드에서 사용할 `/api/chart/{stock_code}/day` API 엔드포인트 생성.
  - **프론트엔드 구현**:
    - `chart-api.ts`: 백엔드 일봉 API를 호출하는 `getDayCandles` 함수 추가.
    - `useTRViewChart.ts`: `timeframe` prop을 받아 분봉/일봉 데이터 요청을 분기 처리하고, 과거 데이터 로드 로직을 일반화.
    - `trview/page.tsx`: `useTRViewChart` 훅을 2번(분봉용, 일봉용) 호출하고, 2개의 `TRViewChart` 컴포넌트를 렌더링하도록 페이지 구조 변경.

- **OHLC 정보창(Legend) 기능**
  - **요구사항**: 차트 위에 마우스를 올리면 해당 캔들의 시가, 고가, 저가, 종가, 거래량 정보를 실시간으로 표시.
  - **조치**: `TRViewChart.tsx`에서 `useState`로 정보 데이터 상태를 관리하고, `chart.subscribeCrosshairMove` 이벤트를 구독하여 마우스 위치의 캔들 정보를 받아와 상태를 업데이트. 상태에 따라 정보창 UI를 조건부 렌더링.
  - **영향 받은 파일**: `stock-trading-ui/src/components/trading/TRViewChart.tsx`

### 2.3. 에러 분석 및 해결 (디버깅)

- **프론트엔드 빌드 에러 (Syntax Errors)**
  - **원인**: `write_file` 사용 시 코드 문자열을 불필요한 따옴표(`'''`)로 감싸, `.tsx` 파일의 시작과 끝에 그대로 쓰여져 구문 오류 발생.
  - **조치**: 오류가 발생한 `trview/page.tsx`와 `useTRViewChart.ts` 파일에서 해당 문자열을 모두 찾아 제거. 향후 파일 수정 시 백업 및 부분 수정을 원칙으로 함.

- **백엔드 422 에러 (Unprocessable Entity)**
  - **원인**: 일봉 API의 날짜 파라미터(`start_date`, `end_date`) 유효성 검사 정규식이 `r"^\\d{...}"`와 같이 잘못 작성됨.
  - **조치**: `chart.py`에서 정규식을 `r"^\d{...}"`로 수정.

- **백엔드 404 에러 (Not Found)**
  - **원인**: '삼성SDI' 등 일부 신규 종목 조회 시, 백엔드에 캐시된 분봉 데이터가 없어 API가 `404 에러`를 반환하고 프론트엔드에서 오류 발생.
  - **조치**: `chart.py`의 모든 데이터 조회 API들이 데이터가 없을 경우 `404 에러` 대신 빈 배열(`[]`) 또는 빈 객체(`{}`)를 반환하도록 수정하여, 프론트엔드가 안정적으로 "데이터 없음"을 처리하도록 변경.

- **백엔드 `DataFrame` 진리값 모호성 에러**
  - **원인**: `chart_cache_service.py`에서 과거 분봉 데이터를 조회할 때, API로부터 `DataFrame` 객체를 받아온 후 `if not df:` 와 같이 잘못된 조건문으로 데이터 유무를 확인하여 에러 발생.
  - **조치**: `DataFrame`을 반환받는 경우, `_convert_df_to_candles` 헬퍼 메소드를 사용해 `List[ChartCandle]`로 먼저 변환한 후, 리스트를 대상으로 조건문을 수행하도록 로직 수정.
