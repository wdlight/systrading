## 📋 사용자 수행 필수 작업 (5분 소요)

### Step 1: 페이지 접속 및 개발자 도구 열기

```bash

2. F12 키 눌러서 개발자 도구 열기
3. "Console" 탭 선택
4. Console 설정 (톱니바퀴 아이콘) → "Preserve log" 체크

```

## 🎯 이 증거가 왜 필요한가?

### 시나리오별 원인 확정

**만약 검색 1 (Hook 초기화)가 없다면**:
→ Hook이 실행되지 않음
→ 원인: `enabled` 또는 `timeframe` 조건 문제
→ 해결: 조건 확인 및 디버그 로그 추가

**만약 검색 1은 있고 검색 2 (구독 요청)가 없다면**:
→ Hook은 실행되지만 WebSocket 연결 실패
→ 원인: `wsManager.isConnected()` === false
→ 해결: WebSocket 연결 상태 확인

**만약 검색 2는 있고 검색 5 (분봉 메시지)가 없다면**:
→ 구독은 했지만 메시지 미수신
→ 원인: 백엔드가 메시지를 보내지 않음
→ 해결: 백엔드 로그 확인 및 분봉 브로드캐스트 로직 점검

**만약 검색 5 (분봉 메시지)가 있다면**:
→ 메시지는 받지만 차트 업데이트 안 됨
→ 원인: 데이터 병합 또는 렌더링 문제
→ 해결: TRViewChart props 전달 및 React 리렌더링 확인
