# 주식 매매 기능 구현 실행 내역

## 📋 프로젝트 개요

**날짜**: 2025-10-11
**브랜치**: bugfix/1011-layout
**목표**: "주식 관리" 메뉴(/trview)에 매수/매도 기능 추가

## 🎯 초기 요청 사항

사용자 요청:
> "현재 시스템에서 매수, 매도를 할 수 있는 UI가 없어. 아마도 backend에는 매수/매도를 할 수 있는 backend 함수가 있을 듯 한데, 검토해 줘. 현재 메뉴중에 "주식관리" 메뉴에 특정 지정가 또는 시장가등 일반 주식 앱에서 제공하는 형태의 매매 기능을 제시해 보려고 해."

### 분석 결과

1. **백엔드 기존 코드 분석** (Serena MCP 사용):
   - `backend/core/order_processor.py`에 `buy_order()`, `sell_order()` 메서드 존재
   - Korea Investment Securities API 연동 완료
   - 자동매매용 API는 있으나 수동 매매용 REST API 없음

2. **프론트엔드 현황**:
   - `/trview` 페이지 존재 (차트만 표시)
   - 매매 UI 컴포넌트 없음

3. **요구 기능**:
   - 지정가/시장가 주문
   - 매수/매도 입력 폼
   - 미체결 주문 조회
   - 체결 내역 조회
   - 호가 단위 자동 조정

## 📝 구현 계획

**계획 문서**: `docs/plan/1011.stock-sale.plan.md`

### 아키텍처 설계

**3단 레이아웃** (12 컬럼 그리드):
- **좌측 (2 cols)**: 차트 컨트롤 패널
- **중앙 (6 cols)**: 분봉/일봉 차트
- **우측 (4 cols)**: 매매 패널 (주문 입력 + 주문 내역)

### 2. API 연동 훅

**파일**: `stock-trading-ui/src/hooks/useOrders.ts`

```typescript
export function useOrders() {
  const [isLoading, setIsLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);

  // 매수 주문
  const placeBuyOrder = useCallback(async (request) => {
    return fetchAPI<OrderResponse>('/api/orders/buy', {
      method: 'POST',
      body: JSON.stringify({ ...request, order_side: OrderSide.BUY }),
    });
  }, [fetchAPI]);

  // 매도 주문
  const placeSellOrder = useCallback(async (request) => {
    return fetchAPI<OrderResponse>('/api/orders/sell', {
      method: 'POST',
      body: JSON.stringify({ ...request, order_side: OrderSide.SELL }),
    });
  }, [fetchAPI]);

  // 주문 정정
  const modifyOrder = useCallback(async (request) => {
    return fetchAPI<OrderResponse>('/api/orders/modify', {
      method: 'POST',
      body: JSON.stringify(request),
    });
  }, [fetchAPI]);

  // 주문 취소
  const cancelOrder = useCallback(async (request) => {
    return fetchAPI<OrderResponse>('/api/orders/cancel', {
      method: 'DELETE',
      body: JSON.stringify(request),
    });
  }, [fetchAPI]);

  // 미체결 주문 조회
  const getPendingOrders = useCallback(async (stockCode?) => {
    const url = stockCode
      ? `/api/orders/pending?stock_code=${stockCode}`
      : '/api/orders/pending';
    return fetchAPI<PendingOrdersResponse>(url);
  }, [fetchAPI]);

  // 체결 내역 조회
  const getOrderHistory = useCallback(async (stockCode?, startDate?, endDate?) => {
    const params = new URLSearchParams();
    if (stockCode) params.append('stock_code', stockCode);
    if (startDate) params.append('start_date', startDate);
    if (endDate) params.append('end_date', endDate);

    const url = params.toString()
      ? `/api/orders/history?${params.toString()}`
      : '/api/orders/history';
    return fetchAPI<OrderHistoryResponse>(url);
  }, [fetchAPI]);

  return {
    isLoading,
    error,
    placeBuyOrder,
    placeSellOrder,
    modifyOrder,
    cancelOrder,
    getPendingOrders,
    getOrderHistory,
  };
}
```

### 호가 단위 규칙

| 가격 범위 | 호가 단위 |
|-----------|-----------|
| 0 ~ 1,000원 | 1원 |
| 1,000 ~ 5,000원 | 5원 |
| 5,000 ~ 10,000원 | 10원 |
| 10,000 ~ 50,000원 | 50원 |
| 50,000 ~ 100,000원 | 100원 |
| 100,000 ~ 500,000원 | 500원 |
| 500,000원 이상 | 1,000원 |

### 수수료/세금 계산

- **매수 수수료**: 거래 금액 × 0.015% (최소 0원)
- **매도 수수료**: 거래 금액 × 0.015% (최소 0원)
- **매도 제세금**: 거래 금액 × 0.23% (증권거래세 0.20% + 농특세 0.03%)
