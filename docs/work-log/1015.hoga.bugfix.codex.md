## 1. 백엔드 WebSocket 안정화
### 1.1 Queue 소비 구조 개선
- `domestic_websocket.py`
  - `multiprocessing.Queue`의 `empty()` 체크가 신뢰할 수 없음 → `asyncio.to_thread(ws_req_queue.get, True, 0.5)` 사용으로 전환.
  - 별도 `process_queue()` 코루틴 생성 → 요청 큐에서 빠르게 소비하며 `종료` 시그널 처리 및 소켓 종료까지 책임지도록 구성.
  - `stop_event`로 메인 수신 루프와 큐 소비 태스크 동기화.
  - WebSocket 수신부는 `asyncio.wait_for(..., timeout=0.5)`로 대기 → 수신이 없을 때도 큐 체크가 주기적으로 가능.

### 1.2 Circuit Breaker 초기화
- 프로세스 분리로 전역 메트릭 수집기가 공유되지 않아 `NoneType.can_attempt` 예외 발생.
  - 자식 프로세스에서 `create_circuit_breaker("websocket_connection", ...)`를 직접 호출.
  - `connect_with_circuit_breaker` 내에서도 방어코드 추가하여 미생성 시 자동 생성.

### 1.3 호가 데이터 파싱 고도화
- KIS WebSocket이 JSON 형식과 `^` 구분 문자열을 혼용 → `recieve_realtime_hoga_domestic_new()`를 명시적으로 정의.
  - 가격/수량만 사용하도록 정규화 (`order_count` 제거).
  - 타임스탬프는 ISO 형식으로 변환하여 프론트에서 즉시 렌더링 가능.
- 기존 JSON 파서(`parse_hoga_json`)도 동일한 구조를 반환하도록 `order_count` 필드 제거.

### 1.4 `/api/realtime` 경로 정비
- `app.state`에 `ws_req_queue`/`ws_result_queue` 저장 → 모든 요청 핸들러에서 일관된 큐 참조.
- `Request` 객체에서 직접 큐를 가져와 사용 (`getattr(request.app.state, ...)`).
- 디버그 엔드포인트 `/api/realtime/debug/queue-status` 역시 state 기반으로 수정.

### 1.5 테스트 업데이트
- `test_realtime_api.py`, `test_orderbook_cache.py`, `test_hoga_parsing.py` 등에서 `order_count` 의존 제거.
- TestClient 사용 시 `app.state.ws_req_queue`에 Mock 주입 → 구독/해제 테스트가 실패하지 않도록 보완.

## 2. 프론트엔드 실시간 렌더링 보강
### 2.1 WebSocket 수신 데이터 정규화
- `useOrderBook.ts`
  - WebSocket, REST(backup)로 들어오는 데이터를 `normalizeOrderBook()`에서 수치형으로 변환.
  - 30초 단위 `fetchLatestSilently()` 도입 → WebSocket이 잠시 멈춰도 REST로 업데이트 유지.
  - `orderBook` 상태는 함수형 업데이트(`setOrderBook(prev => ...)`)를 사용해 race condition 완화.
  - `lastUpdateRef`를 조정하여 초기 로드 직후에도 첫 메시지를 바로 반영.
  - WebSocket 이벤트는 1초 이내 중복 갱신을 무시하여 과도한 렌더링 방지.

### 2.2 UI 헤더/레이아웃 정리
- `OrderBook.tsx`
  - 상단을 `호가창 [HH:MM:SS] 실시간` 한 줄로 표시.
  - 타임스탬프가 없거나 파싱 실패 시 `--:--:--`로 표시.
  - `건수` 열 제거 → 가격/수량 2열 레이아웃으로 단순화.
  - `displayPrice` 계산 시 현재가/중간값 우선순위 및 fallback 정리.

### 2.3 웹소켓 헬퍼 업데이트
- `lib/websocket.ts`
  - `OrderBookUpdate` 타입 사용, `pendingSubscriptions` 관리를 클래스 메서드로 통합.
  - 구독 리스너가 `OrderBookUpdate` 전체를 전달하도록 수정하여 훅에서 필요한 필드만 조합.

### 2.4 타입 및 테스트 반영
- `lib/types.ts`: `OrderBookRow`에서 `order_count` 제거.
- `OrderBook`/`useOrderBook` 테스트: 새 구조에 맞게 목 데이터/검증 변경.
