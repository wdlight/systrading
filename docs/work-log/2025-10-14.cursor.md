### 4. API 엔드포인트 하드코딩 제거
**파일**: `backend/app/api/realtime.py`

**문제점 해결**:
- **이전**: 하드코딩된 더미 데이터 반환 (`current_price = 91600` 등)
- **현재**: 캐시 우선 조회, 캐시 없으면 구독 안내 메시지 반환

**구현된 로직**:
```python
@router.get("/orderbook/{stock_code}")
async def get_current_orderbook(
    stock_code: str,
    realtime_service: RealtimeDataService = Depends(get_realtime_service)
):
    # 1. 캐시 조회
    cached_data = realtime_service.get_cached_orderbook(stock_code)
    if cached_data:
        logger.info(f"캐시된 호가 데이터 반환: {stock_code}")
        return cached_data
    
    # 2. 장 시간 체크
    now = datetime.now()
    is_open = TradingHoursManager.is_trading_hours(now)
    
    if is_open:
        # 장 시간 내: 구독 안내 메시지
        return {
            "message": f"종목 {stock_code}의 실시간 호가 데이터가 없습니다. WebSocket 구독을 시작하세요.",
            "market_status": "open",
            "subscribe_url": f"/api/realtime/subscribe/orderbook?stock_code={stock_code}"
        }
    else:
        # 장 시간 외: 빈 데이터
        return {
            "stock_code": stock_code,
            "current_price": 0,
            "asks": [{"price": 0, "quantity": 0, "order_count": 0} for _ in range(10)],
            "bids": [{"price": 0, "quantity": 0, "order_count": 0} for _ in range(10)],
            "timestamp": now.isoformat(),
            "market_status": "closed"
        }
```
