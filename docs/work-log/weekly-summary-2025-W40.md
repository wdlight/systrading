## 🎓 주간 학습 포인트

### React 패턴
1. **Props Passing vs Context**: 3-depth까지는 props 전달이 명확
2. **Controlled vs Uncontrolled**: 외부 데이터 우선, fallback으로 내부 데이터
3. **Hook 조건부 실행**: `enabled` flag로 불필요한 실행 방지
4. **Multiple Hooks**: 독립적인 데이터 소스를 여러 훅으로 분리

### API 설계
1. **RESTful 원칙**: `/api/{resource}/{action}` 패턴
2. **일관된 응답**: 동일한 스키마 재사용 (ChartCandle)
3. **에러 응답**: 명확한 HTTP 상태 코드
4. **메타 정보**: rt_cd, msg_cd 등 디버깅 정보 포함

### 성능 최적화
1. **캐싱 전략**: 작은 파일 여러 개 > 큰 파일 하나
2. **부분 캐시**: 필요한 데이터만 선택적 로드
3. **메모이제이션**: 계산 비용 큰 작업만 적용
4. **지연 평가**: 사용 시점에 데이터 생성

### 디버깅 방법론
1. **Layer-by-layer**: Frontend → API → Service → 원본 데이터
2. **비교 분석**: 정상 케이스와 비교하여 차이점 발견
3. **로그 활용**: console.log 전략적 배치
4. **원본 보존**: 파싱 전 원본 응답 저장
