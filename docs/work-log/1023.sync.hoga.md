# 2025-10-23 실시간 호가 구독 동기화 작업 기록

## 진행 배경
- `/trview` 화면에서 기본 종목(삼성전자)만 호가가 표시되고 다른 종목으로 전환 시 호가가 갱신되지 않는 문제 확인.
- 프론트엔드 `useOrderBook` 훅이 종목 전환 후에도 기존 구독 상태를 유지하여 백엔드와 WebSocket 구독이 새 종목으로 교체되지 않았음.
- 호가창이 상위 5개 레벨만 표시되고 정렬 순서가 뒤집히는 이슈도 함께 존재.

## 주요 변경 사항
1. **호가 구독 관리 리팩터링 (`useOrderBook.ts`)**
   - `useState`로 관리하던 `isSubscribed` 대신 `subscribedStockRef`(ref)로 현재 구독 중인 종목을 추적.
   - `sendUnsubscribe()` 유틸을 추가해 REST `/api/realtime/unsubscribe/orderbook` + WebSocket `unsubscribe`를 함께 호출하도록 통합.
   - 새 종목 구독 전에 이전 종목을 반드시 해제하고, 성공 시 `subscribedStockRef.current`를 갱신.
   - `isSubscribingRef` 플래그를 도입하여 구독 진행 중 동시 호출을 차단하고 레이스 컨디션 방지.
   - 종목 변경 시 `orderBook` 상태와 캐시(`lastUpdateRef`)를 초기화해 이전 데이터 잔존을 방지.
   - `useEffect` cleanup에서 `unsubscribe()`를 호출해 언마운트/종목 전환 시 구독이 남지 않도록 수정.
   - 자동 구독 효과(`useEffect`)가 새 종목 코드를 의존성으로 삼아 즉시 재구독하도록 재구성.

2. **호가 정렬/표시 개선 (`OrderBook.tsx`)**
   - 매도/매수 호가 배열을 `price` 기준 내림차순 정렬해 가장 높은 가격이 상단에 오도록 조정.
   - `.slice(0, 5)` 제한을 제거해 KIS에서 제공하는 모든 호가 레벨을 표시.
   - 실시간 하이라이트 비교(`diffOrderLevels`)가 정렬된 전체 배열을 기준으로 동작하게 변경.
   - 호가 바 차트 폭 계산(`maxQuantity`)도 전체 레벨을 고려하도록 유지.

3. **분봉 차트 현재가 하이라이트 추가 (`TRViewChart.tsx`)**
   - `createPriceLine`을 이용한 `flashPriceLine()` 함수 도입: 최신 분봉 가격에 가격선을 생성하고 0.7초 후 자동 제거.
   - 분봉(`timeframe === 'minute'`)에서 마지막 캔들의 `timestamp`/`close`가 변경될 때마다 하이라이트 실행.
   - 언마운트 시 타이머와 가격선을 정리해 메모리 누수 및 다중 라인 생성 방지.

## 확인 결과
- `/trview`에서 다른 종목을 선택하면 콘솔에 이전 구독 해제 및 새 구독 시작 로그가 정상적으로 출력되고, 호가창이 해당 종목 데이터로 갱신됨.
- 호가창에 전체 레벨이 가격 높은 순으로 표시되며 분봉 차트에서도 현재가 하이라이트가 동작.
