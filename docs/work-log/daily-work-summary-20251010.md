# 2025-10-10 작업 요약

## 프런트엔드
- Next.js 개발 문서 및 스크립트의 기본 포트를 9000으로 정리하여 문서-실행 불일치 제거.
- `stock-trading-ui/src/hooks/useTRViewChart.ts` 리팩터링
  - 초기/주기 로딩 시 최신 100개의 캔들만 유지하도록 제한.
  - 과거 데이터 로드 시 중복 합치기 및 확장 상태 플래그 추가.
  - 일봉 차트는 60초 간격으로 자동 새로고침.
- `TRViewChart` 컴포넌트에 초기 가시 범위 제어 옵션을 도입해 분봉/일봉 차트가 기본적으로 100캔들만 렌더링하도록 조정.
- KST 기준 시간 포맷터 추가로 축/툴팁 시간 표시가 통일되도록 수정.
- 대시보드 레이아웃을 12컬럼 2열 구성으로 재정비하고 KPI/성과 영역을 카드 기반으로 재구성.
  - `AssetPanel`, `PortfolioPerformanceChart` 등 신규 컴포넌트를 추가해 보유 종목/성과 차트를 통합.
  - `QuickActionPanel`을 모바일 시트 및 포커스 트랩 기반으로 재작성하고 알림 드롭다운을 별도 컴포넌트로 분리.
  - 공통 `EmptyState`/`ErrorState` 컴포넌트를 도입해 보유종목·관심종목·마켓 오버뷰의 예외 처리를 일원화.
- `focus-trap-react`와 `useLocalStorage` 훅을 도입해 알림/포트폴리오 mock 데이터를 관리하며 API 연동 전 UI 상호작용을 검증.

## 백엔드
- Gap fill 시 타겟 날짜가 아닌 분봉은 폐기하도록 필터링하여 다른 일자 데이터가 캐시에 섞이지 않도록 보호.
- 분봉 데이터를 집계해 당일 일봉을 실시간 생성하는 헬퍼 추가 및 `get_day_chart_data`에서 오늘 데이터가 없을 때 자동 병합.
- Gap fill API 호출에 `target_date` 전달 및 과거/당일 분기 로직 강화.
- 일봉/분봉 캐시 저장 과정에서 불필요한 중복 저장을 줄이기 위한 병합 로직 보강.

## 기타
- 차트 갭 필터링 및 일봉 생성 변경 후 캐시 파일에 이전 거래일 데이터가 섞이는 문제 재발 여부 수동 확인.
- 초기 로딩 후 차트 자동 확대 문제를 추적하고 재로딩 시에도 제한이 유지되는지 확인.
