# 2025-10-13 Codex 변경 내역

## 개요
- 한국투자 API 비동기 래퍼 `_run_in_executor`가 키워드 인수를 넘기지 못해 체결/미체결 조회가 모두 실패한 문제를 해결했습니다.
- 일봉 차트 API 흐름에서 `date` 객체 처리 미흡으로 발생한 예외를 수정하여 `/trview` 일봉 차트를 복구했습니다.
- 지수 조회 성공 로그를 비활성화하고, 실패 상황에서만 에러 로그가 남도록 조정했습니다.
- 체결 내역 응답에 누락되어 있던 총계 필드를 계산/반영해 프런트엔드 표시 누락을 방지했습니다.
- 관련 유틸리티(`TradingCalendar`)의 타입 대응 개선과 테스트 실행 내역을 기록했습니다.

## 상세
1. `backend/app/core/korea_invest.py`
   - `_run_in_executor`에서 `functools.partial`을 사용해 키워드 인수를 안전하게 전달하도록 수정했습니다.
   - 지수 조회 성공 로그(`logger.info`)를 주석 처리하고, 파싱 실패 시에만 `logger.error`가 출력되도록 변경했습니다.

2. `backend/app/utils/trading_calendar.py`
   - `is_trading_day`가 `datetime.date`와 `datetime` 모두를 처리하도록 보강했습니다.
   - 변경 확인을 위해 `./vkis/bin/python -m pytest tests/test_trading_calendar_range.py`를 실행했습니다.

3. `backend/app/services/order_service.py`
   - 체결 내역 조회(`get_order_history`)에서 매수/매도 금액, 수수료, 세금 합계를 계산해 `OrderHistoryResponse`에 포함하도록 수정했습니다.

## 영향 및 후속 조치
- `/api/orders/history`와 `/api/orders/pending` 호출이 정상 처리되며, 프런트 `/trview` 페이지에서 일봉 차트가 다시 노출됩니다.
- 백엔드를 재시작해 변경 사항이 반영됐는지 확인하고, 체결/미체결 조회 API를 수동 호출해 결과를 검증하는 것을 권장합니다.
